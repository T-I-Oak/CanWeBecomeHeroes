# 計画: チュートリアルの実装

## 開発スコープ

- チュートリアルの実装
  - `GameWorksOAK` の共通ライブラリのチュートリアル機能を使用して実装する。
  - 説明役として「ギルドマスター」を登場させる。
  - ギルドマスターは勇者試験の合格証明書を出す役割とする。

## 対象外

- 設定画面のチュートリアルリセット機能（本フェーズ完了後の別タスクとして着手予定）。
- その他の無関係なバグ修正や機能追加。

## 完了条件

- チュートリアルが意図したタイミングで開始され、正常に進行・完了すること。
- ギルドマスターによる説明テキストや演出が正しく表示されること。
- 共通ライブラリのチュートリアル機能を用いた実装になっていること。

## 実装・テスト方針

- **実装方針**:
  - `GameWorksOAK` 共通ライブラリのチュートリアル関連機能（UI、状態管理など）の仕様を確認し、`CanWeBecomeHeroes` の要件に合わせて組み込む。
  - **[重要] チュートリアルの具体的な内容（説明テキスト、進行シナリオ、対象となる操作など）については、実装を進める前にオーナーと打ち合わせを行い、仕様を確定させてから実装する。**
  - ギルドマスターの立ち絵やテキストデータなどのリソースを準備し、チュートリアルシナリオに適用する。
- **テスト方針**:
  - チュートリアルの開始、進行、終了が正しく状態管理されるかの単体テスト。
  - モバイルおよびデスクトップ表示でのチュートリアルUI（情報ウィンドウなど）の表示確認。
  - 手動検証として、チュートリアルの一連のフローが途切れずに完了するかを通しで確認する。
