## シミュレーションで確認すること

- タグ・武器・施設・敵を手動指定し、候補一覧と複数の生成結果を確認する。
- 生成結果ごとに、選んだ構成・展開経路・語句の参照元を表示する。
- 汎用だけの結果、同一カテゴリーを複数回使う結果も許容する。
- 深さまたは文字列長による終端選択を調整できるようにする。数値はシミュレーション用であり、本番仕様の確定値とは扱わない。
- 構成・語句は編集できる案とし、結果を見ながら調整する。語句の採用はオーナーとの相談で決める。
