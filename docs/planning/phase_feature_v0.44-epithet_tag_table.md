## 語句整理の相談事項

- 軽業の「走者」はオーナー提案の「マジシャン」へ変更。
- 雷の「走者」は「先駆者」へ仮変更。雷との関連は引き続き検討する。
- 「泉の守り手」のような修飾付きの人は固定登録せず、形容詞「泉の」と人「守り手」を分け、汎用の`[形容詞（味方）][人（味方）]`で組み合わせる案。
- 水の形容詞は「泉の」とし、人は「守り手」と分離する。
- 「守り手」を鉄の人へ配置するというオーナーの指摘を記録。鉄の「守護者」との整理、および加護にある「守り手」の配置は検討中。
- 他の「○○の守り手」等の固定表現も、同じ観点で分離を検討する。
- 「幸運の使者」も固定登録せず、幸運の形容詞「幸運の」と人「使者」に分離する。形容詞案の「運に愛された」を「幸運の」に差し替えた。「使者」の配置先は未決定で、汎用の人（味方）に置く案を提示する。

## 重複チェック

使い手・使者・守り手は汎用の人（味方）へ集約し、対象間の重複を解消した。「清らかな」は水に配置する。

形容詞へ分離して追加する候補：羽「風の」、炎「炎の」、水「水の」、雷「雷の・雷鳴の」、範囲「陣の」、活力「生命の」。既存形容詞との入れ替え候補はオーナーと検討する。追加後は水・範囲・活力が5候補、雷が6候補となるため、この時点では既存語句を削除しない。
