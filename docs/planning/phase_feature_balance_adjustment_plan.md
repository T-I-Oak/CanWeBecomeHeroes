# 計画: タグ相性・Exスキル全体数値見直し

## 開発スコープ
- バックログ「2. タグ相性に基づいて数値を調整する」の対応として、ゲーム内の全体的な数値バランスを必要に応じて見直す。
- タグ相性シミュレーションを基準に、以下の項目のうち**調整が必要と判断されたもの**について対応する。記載されているすべての項目を見直すことを必須とはしない。
  - 最優先事項: 聖印の効果量（回復量）の適切な再定義。
  - 戦闘基礎数値: アクションゲージの蓄積量、与ダメージ・被ダメージの計算式、敵HP。
  - ゲーム進行: 貢献ポイント、報酬（ドロップ量など）、敵編成。
  - 固有スキル: 各Exスキル（中ボス・ボス専用スキル）の効果量や確率。

## 対象外
- 新しい武器種や新しいタグの追加など、数値調整の枠を超える新規機能の開発。
- UIの大幅なレイアウト変更（数値を表示するための軽微な修正は許容する）。

## 完了条件
- 聖印を含む、見直し対象として選定された各数値・計算式が再定義され、ゲームコードに反映されていること。
- 実装した調整による対象テスト、全体テストがすべて成功すること。

## 実装・テスト方針
- 実装に入る前に、まずは具体的な調整値（聖印の新しい効果量や、見直しが必要なその他の数値）を算出し、オーナーと合意する。
- 確定した仕様に基づいてコードを修正し、既存のテストコードを新しい計算結果に合わせて更新・追加する。
