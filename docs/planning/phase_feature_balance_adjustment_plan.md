# 計画: タグ相性・Exスキル全体数値見直し

## 開発スコープ
- バックログ「2. タグ相性に基づいて数値を調整する」の対応として、ゲーム内の全体的な数値バランスを必要に応じて見直す。
- タグ相性シミュレーションを基準に、以下の項目のうち**調整が必要と判断されたもの**について対応する。記載されているすべての項目を見直すことを必須とはしない。
  - 最優先事項: 聖印の効果量（回復量）の適切な再定義。
  - 戦闘基礎数値: アクションゲージの蓄積量、与ダメージ・被ダメージの計算式、敵HP。
  - ゲーム進行: 貢献ポイント、報酬（ドロップ量など）、敵編成。
  - 固有スキル: 各Exスキル（中ボス・ボス専用スキル）の効果量や確率。

## 対象外
- 戦闘時間の短縮に伴う試験難易度・試験期限の再調整。今回の目的であるタグ・属性間の格差縮小は達成したものとし、この課題はバックログ末尾で別途扱う。
- 新しい武器種や新しいタグの追加など、数値調整の枠を超える新規機能の開発。
- UIの大幅なレイアウト変更（数値を表示するための軽微な修正は許容する）。

## 完了条件
- 聖印を含む、見直し対象として選定された各数値・計算式が再定義され、ゲームコードに反映されていること。
- 実装した調整による対象テスト、全体テストがすべて成功すること。

## シミュレーションの前提整備と担当

- オーナーとの追加合意により、数値調整の前にExスキルを含むシミュレーションを整備する。
- 戦闘と移動・実体管理・装備回収・帰還の既存オブジェクトを、シミュレーション側のドライバーから利用する。画面表示は不要とする。
- アプリ側へシミュレーション機能を追加せず、既存ゲームコードを変更しないAの方式を採用する。実現可能性調査は `phase_feature_balance_adjustment_feasibility.md` に記録する。
- AIは数値案を作成しない。オーナーが対戦条件を指定し、AIが結果を集計し、オーナーが数値案を作成する。

## 実装・テスト方針

### 合意したゲーム適用値

- オーナーの適用指示により、武器の攻撃倍率は標準1・中2/3・小1/2・微小1/3を採用する。素手も微小として扱う。
- 聖印は確定回復を維持し、回復量は有効加護タグ数×0.01＋0.01を採用する。発動確率50%の試算値は適用しない。
- 追加のオーナー指定により、水の命中式と水・炎・信用のExスキルも調整した。最終採用値は実装報告の「最終採用状態」を参照する。アクションゲージ、敵HP・編成、貢献ポイント、報酬は今回変更していない。
- 数値調整に入る前に、指定された対戦条件の結果を集計し、オーナーが提示する具体的な調整値を確定する。シミュレーションの前提整備は先に実施する。
- 確定した仕様に基づいてコードを修正し、既存のテストコードを新しい計算結果に合わせて更新・追加する。
