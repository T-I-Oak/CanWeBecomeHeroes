# Hero会話用設定資料（初稿）

Heroの情報ウィンドウ、ゲーム開始時の組合せ会話、加入イベントで共通に使う会話設定資料。

## 扱い

- **確定**: 職業、名前、固有タグ、剣士と衛兵が幼なじみであること。
- **会話用初稿**: それ以外の人物像、勇者を目指す背景、口調、将来の会話の方向性。実装仕様ではなく、台詞作成前にレビューして確定する。
- 試験前からの知人として確定している組合せは、現時点では剣士・衛兵だけ。他のHero同士は、特別な関係を後から定義するまでは試験で初めて出会う。

## 共通方針

- Heroは完璧な英雄ではない。少しだらしなさや未熟さを持ちながらも、それぞれ自分なりの理由で勇者を目指す。
- 一人称、口調、相手の呼び方は、短い加入会話でも識別できる程度に差を付ける。口癖は毎文に使わず、感情が出る場面に限定する。
- Hero情報ウィンドウの紹介文は解放状態で差し替えない。関係性は固定紹介に含め、ゲーム開始時の組合せ会話と加入会話で個別の出来事として表現する。
- 加入会話は加入するHeroを基準に定義する。Party内に対応するHeroが複数いる場合は、該当する会話候補からランダムに1つを選ぶ。該当者がいない場合は通常加入会話を使う。

## 次の検討事項

- 会話用初稿をレビューし、各Heroの背景・一人称・口調を確定する。
- Heroごとの通常加入会話を、加入Hero側の定義として作成する。
- 剣士→衛兵、衛兵→剣士の特別加入会話を作成する。
- 将来、試験前からの知人を追加する場合は、この資料の「関係」を確定情報へ移す。関係を追加しても、既存の固定紹介文を解放状況で差し替えない。
