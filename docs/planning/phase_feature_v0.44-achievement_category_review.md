- タグカテゴリーは現行実装で能力系10タグのみ。炎・水・雷・範囲・活力はこのアチーブメント一覧に含まれない。二つ名用の15タグとは対象が異なる。
- チャレンジ開始の項目は既存アチーブメント定義に含まれる。チャレンジ結果画面の今回スコープ外という扱いとは別。
- カテゴリー名と各項目の所属をこの一覧でレビューし、合意後に変更する。
