# 二つ名の対象一覧と語句リスト案

> 位置づけ：参考情報。掲載した語句・分類・配置は採用済みの定義ではなく、再検討の材料として保存する。現状の語句表をそのままシミュレーション・本番実装へ使用しない。展開ルールは別文書で管理する。

## 進め方

まず対象ごとの語句リストと汎用リストを作る。その後、作成したリストを使い、カテゴリーごとに対象を指定してシミュレーションする。事前に4対象へ絞る進め方は採用しない。

語句は「人／動詞／形容詞」×「味方／敵／共通」の9区分で管理する。単語だけでなく句・再帰テンプレートも候補にできる。個別対象ですべての区分を埋める義務はない。

「人」は人を表す名詞・表現に限定する枠。一般的な物・象徴の名詞はこの枠へ入れない（オーナー指定）。

対象別の語句数は各品詞で合計4候補程度を目安とし、味方は最低2候補を用意する。残りは敵・共通へ対象に合わせて配分する。例：味方2・敵2／味方2・敵1・共通1／味方2・共通2／味方3・敵1。各区分へ4候補ずつ用意する規則ではない。

全情報種別で各品詞4候補以上を最終目標とする。全項目は参考候補として記録し、よりふさわしい案に応じて移動・交換・入れ替えを行う。一時的に4候補未満でもよい。5候補以上になった場合は廃案にする候補をオーナーと相談する。重複チェックは随時行う。敵カテゴリーは敵ごとの語句リストを作らず、敵名称を差し込む共通定義を作る。使用区分の「共通」や「汎用リスト」とは区別する。

ベース構成や味方・敵欄の語句内の展開指定は、品詞と「味方／敵」のどちらかを指定する。例外として、語句リストの共通欄にある語句内では「共通」の展開指定も使用できる。味方の展開では該当品詞の味方・共通候補を、敵の展開では該当品詞の敵・共通候補を参照する。使用区分の共通と、特定対象に依存しない汎用リストは別の概念とする。「共通」指定時の候補参照範囲はまだ明示されていない。

## 汎用リストの再帰構成

- 人（味方）：`[形容詞（味方）][人（味方）]`（オーナー指定）。構成要素の連結を意味し、「＋」を結果に表示しない。
- 「勇敢な戦士」のように修飾語と人を固定した候補は、武勇のリストに含めない。先に抽出した語句候補から形容詞・人を選び、汎用の再帰構成で組み合わせる。

再帰候補は終端語句と併存させる。深さまたは文字列長に応じた終端選択を適用する。
