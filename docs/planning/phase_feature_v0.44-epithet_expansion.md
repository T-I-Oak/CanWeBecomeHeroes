# 二つ名の展開ルール

## 確定したルール

- 語句定義とは別に「二つ名の構成データ」を持ち、これを生成の起点とする。ベース構成をランダムに選択し、集約済みの候補で構成内の可変部を展開する。
- 現在の起点は`[person(ally)]`とする。personはperson_baseをそのまま使う構成と、modifierを1つ付ける構成を持つ。味方・敵に同じ分離を適用する。別のベース構成は独断で追加しない。
- データの英語識別子はperson／qualifiedPerson／modifier／action、使用区分はally／enemy／commonを採用する。
- 構成・語句のテンプレートは言語別リソースとする。空白・接続語・語順は言語別テンプレートで指定し、展開処理が自動挿入しない。すべての言語で後置する制約は設けない。
- 敵のperson(ally)は日本語`[person_base(enemy)][actionPerson(enemy)]`、英語`[person_base(enemy)] [actionPerson(enemy)]`とする。actionは行為部分、actionPersonは人を含む表現として分ける。武勇・加護にはactionPerson(enemy)を定義する。通常のactionPerson(enemy)候補が空の場合だけ、デフォルトの`[action(enemy)][person_base(ally)]`を展開する。合成構成を情報共通の通常候補には混ぜない。
- 情報種別ごとに語句カテゴリーと候補を定義する。情報共通（汎用）の定義も用意する。
- 4カテゴリーから選択した対象に対応する情報種別の定義と、情報共通の定義をすべて集め、語句カテゴリー別の候補を揃えてから展開を開始する。
- 展開時はこの集約済み候補を参照する。個々の情報種別を別々に展開したり、可変部ごとに一つの情報種別へ固定したりしない。
- 同一情報カテゴリー由来の語句が複数回使われる結果や、情報共通の語句だけで完成する結果も許容する。
- 「情報共通」は対象に依存しない定義を指す。語句候補の使用区分「共通」とは別であり、情報共通の定義にも味方／敵／共通の候補を持たせられる。
- 構成や語句に含まれる角括弧`[...]`は展開を表す。
- 角括弧内の語句カテゴリーからランダムに候補を選び、展開する。
- 語句カテゴリー名は「人」「形容詞」「動詞」に限定せず、任意の文字列を指定可能とする。末尾の(味方)／(敵)／(共通)はカテゴリー名と分けて絞り込み指定として解釈する。
- 語句カテゴリーを安易に追加しない。追加が必要な場合は、必要性と候補をオーナーと一緒に検討して決定する。任意のカテゴリー名に対応できる仕組みは、実際のカテゴリーを独断で追加する許可ではない。
- 角括弧内末尾の丸括弧は、抽出対象を絞り込む指定として扱う。
- 展開時に、指定したカテゴリー・使用区分で絞り込んだ通常候補が存在しない場合は、デフォルト定義を参照する。デフォルト候補を通常の候補集合に混ぜず、通常候補がある場合は選ばない。
- デフォルトは展開のキーワード（person等）とフィルター（ally／enemy／common／指定なし）の組み合わせごとに用意する。通常候補が空の場合、同じ組み合わせに対応するデフォルトを参照する。
- 例：`[person(enemy)]`の通常候補が空の場合、敵名の代わりに「強敵」のようなデフォルト候補で展開できるようにする。現行のdefault一覧は本番データpublic/data/epithet.jsonを参照する。

| 指定例 | 候補の範囲 |
| --- | --- |
| `[人(味方)]` | 人の味方＋共通 |
| `[人(敵)]` | 人の敵＋共通 |
| `[人(共通)]` | 人の共通のみ |
| `[人]` | 人の味方＋敵＋共通（絞り込みなし） |

例：`炎の[人(味方)]`では「炎の」は固定し、人の味方＋共通から選んで展開する。

構成・味方欄・敵欄では原則として味方か敵を指定するという既存ルールと、共通欄の語句内では共通指定も使用できる例外は維持する。本書の絞り込みなしの定義だけで、それらの記述場所のルールを撤回したとは扱わない。

## 継続して検討する事項

- 名詞は現時点では追加しない。「炎の」などの表現は形容詞で定義できる。
- 単独で使用できる呼び名は「人」、修飾が必要な呼び名は「修飾人」と区別する。汎用の使い手・使者・守り手は修飾人（味方）に分類し、人には含めない。
- 情報共通のperson(ally)は`[person_base(ally)]`、`[modifier(ally)][person_base(ally)]`、`[modifier(ally)][qualifiedPerson(ally)]`。person(enemy)は`[person_base(enemy)]`、`[modifier(enemy)][person_base(enemy)]`。personから同じpersonへ直接再帰してmodifierを重ねる構成は置かない。
- person_baseは呼び名・敵名を持ち、循環参照にならない組み立て定義も許容する。敵由来構成はperson(ally)へ置き、`[person_base(enemy)][actionPerson(enemy)]`から展開する。actionPerson(enemy)のdefaultは`[action(enemy)][person_base(ally)]`と`[action(enemy)][modifier(ally)][person_base(ally)]`とし、personの構成へ戻らない。終端default「勇者」「強敵」は対応するperson_baseのdefaultへ置く。
- 語句内の参照は再帰展開する。深さまたは文字列長によって終端候補を選ぶ。
- 本番では深さ12以降に終端候補を優先する。展開10000回の異常停止を設け、現行構成は循環参照を作らない。シミュレータの通常生成には深さ制限を設けない。
