## シナリオと観測点

| 計画のシナリオ | 検証内容 |
| --- | --- |
| 親子の参照と置換 | 生成したHeroの装備ボタンからItem、タグ、重量を順に開く。描画された4つのタイトルと親子関係、最深部へのフォーカスでの祖先維持、別プロパティによる子孫の置換を確認する。 |
| 内外のタップと閉じる | ピン止めした子を保持して別の子を開く。子・親・外側へのフォーカスで残る描画と、閉じるボタンによる固定済みの親子の終了を確認する。 |
| ピン止めと時間停止 | 描画されたピンボタンと停止設定を切り替え、GameClockのadvanceで時間が進むかを観測する。手動停止・課題選択・自動停止に相当する別理由が解除されないことも確認する。 |
| 静的情報と実体情報 | Hero・Enemy・Item・固有スキルの定義をタイトル・本文と実体ゲージ等の不在で識別する。実体では装備5枠・タグ数・重量・Itemの重量と価値を観測する。 |
| 表示中の更新と消滅 | Heroスタミナ3→1.5、Enemy HP3→2の変更後に実際の描画ゲージの区分と充填率を確認する。固定したHero実体を含む対象の消滅と再描画を確認し、定義情報が残ることを確認する。 |

実際のInformationWindowManager・InformationWindowLayer・文言リポジトリ・GameClock・EntityRegistry・各Factoryを使用する。DOMの保存・検索・イベント配送のみをテスト内の最小環境で代替し、Canvas描画は実行しない。アイコン・ピン・閉じるは描画層が登録したclickハンドラーを実行する。内外タップはGameAppが判定したIDを受け取るManagerのfocus境界で検証するため、ブラウザーのイベント伝播や座標のヒット判定まで検証したものではない。

既存の実装テストは、木構造の詳細、位置・倍率・ドラッグ、翻訳網羅、個々の表示契約を引き続き担当する。本番コード、ブラウザー接続、共通ライブラリは変更していない。

## 検証結果

- `node --test tests/spec/05.information_window.test.js`: 5件成功、失敗0件。
- `npm.cmd test`: 580件成功、失敗・スキップ0件（約57.2秒）。
- `npm.cmd run build`: 成功。212モジュールを変換し、本番bundleを出力した。
- `git diff --check`: 成功。
- `npm.cmd run test:browser`: ブラウザー接続の追加・変更がないため、計画の条件に従って実行対象外。

作成途中の対象テストでは、仮置きしたHero名と、親実体の消滅時に生存している装備実体の表示も消えるとした期待値で失敗した。前者は実際の名称リソースを参照する検証へ修正した。後者は要件05の「実体IDを指定した情報ウィンドウだけは、対象実体が消滅したときに閉じる」に照らし、装備実体が生存中は表示でき、装備自体の消滅時に閉じることを検証するよう修正した。閉じるボタンで親子を閉じる要件は別シナリオで維持している。製品修正は行っていない。

全対象・全表示文言・CSSの見た目・Canvas画像・実機タップ精度・固有スキルの効果計算は対象外。既存の保留中オーナー検証を維持する。画面挙動やデザインを変更していないため、新たなオーナー検証項目は提示していない。今回の範囲で追加のオーナー判断を要する事項はない。
