# 成績表の既知項目表示の実装報告

## 対象と実装結果

- ブランチは`feature/v0.72-known-achievements`、確認バージョンは`0.72.0`。
- オーナーの実装中の指示に従い、D-以上への到達では既知フラグを更新しない。レコード表示時に現在の評価がD-以上、または保存済み既知フラグがtrueの項目を定義順に表示する。
- 結果画面の表示項目が確定した時点で、選定した項目だけをEも含め既知にし、終了記録とともに保存する。裏面の閲覧は条件にしない。
- トーストの表示待ち・通知抑止、裏返し・画像共有・レコード閲覧・言語切替で既知状態や集計を更新しない。
- 表示対象がない場合は空の表を生成せず、日英の案内文を表示する。空状態は画面幅で折り返し、表用の論理幅や縮小を使わない。
- 独自の保存形式バージョンは設けない。全定義IDの真偽値を`knownAchievements`へ保持する。データ未保存の新規作成と不正な保存データを区別し、旧形式の補完・既知状態の推定・自動移行・不整合時の黙示的な初期化を設けない。
- 保存失敗時のメモリ保持と絶対状態の再保存を維持する。繰り返し既知化・終了通知・保存で集計を重複加算しない。
- 要求・仕様・計画を上記の指示に合わせ、実装済みの対象項目をバックログの新規要望から削除した。保存済み引継ぎ書は変更していない。

## 主な変更箇所

- `RunRecordsRepository`: 既知フラグの初期値・対応形式チェック・既知化API。
- `TrialSession`: 結果選定後、モーダル表示前の既知化と終了記録の保存。
- `RecordScreenData`・`RecordScreen`: 表示時の評価と既知フラグによる絞り込み、空状態の案内。
- `RecordScreenScale`: 空状態の画面幅への追従。既存の表の縮小・スクロールは維持。
- `public/data/text/ui.json`: 日英の案内文。
- `package.json`・`package-lock.json`: 初回実装開始時の`0.72.0`への更新。
