# 計画: 操作の実装とモバイルビュー調整

## 開発スコープ
バックログの「1. 操作とゲーム画面を拡充する」のうち、チュートリアル実装の前提となる「操作」に関する以下の3点を含めて実装を行います。

1. **エッジスクロール機能の実装**
   - チップのドラッグ中にポインタが画面の周囲一定距離内に入った場合、カメラを自動スクロールさせる。
   - 画面外へポインタが出た場合自体はスクロール判定としない。
2. **水滴表示のドラッグ対応**
   - 水滴表示に対してドラッグの入力判定を追加し、チップと同様に選択の始点・終点の対象として扱えるようにする。
3. **モバイルでの操作確認とビュー調整**
   - 以下の操作について、モバイル（タップ・ドラッグ）で想定通り動くかを確認するための操作一覧を作成し、確認を行う。
     - タップでの情報ウィンドウ開閉
     - ドラッグでのチップ移動・入れ替え
     - 追加したエッジスクロール動作
     - 追加した水滴表示のタップ・ドラッグ
   - 上記の確認と併せて、カメラの初期倍率や各エリアのビュー調整（ダイアログ等の画面収まり確認）を行う。

## 対象外
- バックログ「1. 操作とゲーム画面を拡充する」内の以下項目（操作仕様が確定した後の別ブランチで着手します）
  - 説明書とチュートリアルの実装
  - チュートリアルリセット機能の実装
- その他、既存バグ修正（ブロッキングバグを除く）

## 完了条件
- 1, 2の機能が要求通りに動作すること。
- モバイル操作の確認項目が一覧化され、3のビュー調整と合わせて想定通りに動くことが確認されること。
- 対象テストおよび全テスト、本番ビルドがパスすること。

## 実装・テスト方針
- **実装方針**:
  - ドラッグ関連のイベント処理を拡張し、スクロールや水滴表示の判定を追加する。
  - モバイルのビュー調整は CSS（Viewport 単位等）やカメラ設定を調整して対応する。
- **テスト方針**:
  - 入力制御に対する対象テストを追加・更新する。
  - 実装完了後に全テストと本番ビルドを実行し、デグレがないことを確認する。
