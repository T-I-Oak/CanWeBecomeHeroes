# 試験ラン記録ブランチの計画

## 現在のスコープ（オーナー合意済み）

ブランチはcodex/v0.42-trial-records。初回実装のバージョンは0.42.0。フェーズ全体の完了・コミット・マージはまだ行っていない。

今回の対象は以下に限定する。

- 基礎情報の収集：今回ラン・累積の集計、ゲーム成立時のフック、ギルド消費貢献ポイントを含む確定した項目。
- 保存：課題決定時・ゲーム終了時の保存、終了履歴と通算統計、旧データ維持、二重集計防止。
- アチーブメント：JS定義、計算値の取得、グレード式・段階テーブルによる評価、所見と通知段階の選択、前回との比較。言語別リソースは定義生成側で差し込み済みとする。
- ランキング：終了結果の収集、モード・基準別順位、各上位10件の和集合の保持と保存。
- 終了情報と更新通知を後続UIへ渡せるデータ・コールバックの接続。

## 後続ブランチへ移す範囲

トースト、レコード画面（アチーブメント・ランキング）、終了画面へのアチーブメント表示、共通CSS・DOM生成、利用者向けの保存エラー表示・再試行操作は今回の対象外とする。

合格・不合格通知を土台にする終了画面のデザインを先に決め、それに合わせて共通表示を実装する。合意した表示方針・評価項目名・所見は仕様書に保持する。表示件数上限・画面レイアウト等は今回の完了条件ではない。

## その他の対象外

チャレンジモードのゲーム進行、二つ名の選定・表示、ログ履歴画面、途中セーブ・再開、Hero解放タイミングの変更、共通ライブラリの変更は含めない。

## 実装・確認

仕様の正本は14.achievements.md、15.achievement_classes.md、16.run_records.md。タスクの現在状態はphase_codex_v0.42-trial-records_tasks.mdで管理する。

Codexが論理テストと本番ビルドを実行する。今回の処理にはユーザビリティ確認用のUIを新設しない。フェーズ終了は既定の引継ぎ草案承認手順で行い、スコープ変更だけで完了としない。
