# v0.44.0 正式な試験終了画面：実装報告

## 実装した結果

試験モードの仮終了画面を、合格証明書／不合格通知と成績表を1枚の紙の表裏として表示する正式画面へ置き換えた。終了情報を一度だけ作成し、表裏の操作で成績選定・二つ名生成・記録保存をやり直さない。

- 固定比率7:5で内部の840×600レイアウトごと拡縮する。操作は静止した裏返し矢印とタイトル復帰のみ。ページ番号、前／次ページ、ボタンのツールチップは表示しない。
- 合格証明書は認定メッセージ、終了メンバー順の二つ名と名前、終了日、委員会とゼインの役職・名前・サイン、画像生成した認定印を表示する。二つ名は名前より小さい。
- 不合格通知は結果・再挑戦を待つメッセージ、終了日、委員会名だけを表示する。
- 成績は最大10件。累積グレード更新を優先し、空きは今回ランの未丸めG値で補充する。同点は定義順、表示全体も定義順。判定・所見は累積評価を使い、更新した判定だけ赤字とする。同カテゴリーの連続行を結合する。
- 敵種ごとの討伐45項目は課題攻略へ、ギルドで消費したポイントの評価は施設利用へ統合した。数値の収集・計算・保存形式は変更していない。
- 第7課題も全滅直後に課題クリアーを記録し、既存の勝利待ち時間が終わってから合格画面へ移る。待機中に期限到達した場合も、クリアー済みなら合格とする。
- 合格は紙吹雪先行、透明で大きい紙面から通常サイズへ縮小。不合格は中央の「試験終了」を3秒表示（フェード各450ms・保持約2.1秒）した後、紙面を中央から拡大する。ボタンは拡縮しない。文字背景には暗い帯を配置した。
- 紙吹雪は9×16px、短辺の見かけ幅が変わる回転付き。表示後に上から落下し、初回は多めから減衰、少量を閉じるまで継続する。DOMの除去で演出も停止する。

## 二つ名

終了メンバーの今回ランの実数を比較する。各情報種別で本人の獲得率を求め、タグ・武器・施設・敵それぞれ最大のものを選ぶ。合計0と本人の実績0は除外し、同率はランダムとする。選んだ対象と共通の語句を集めてから展開するため、採用語句の情報カテゴリーは結果ごとに変わる。

- 起点は`[person(ally)]`。敵由来の構成は`[person_base(enemy)][actionPerson(enemy)]`。
- `actionPerson(enemy)`のdefaultには、勇者の直前に修飾を置く形も含める。敵名の前へ修飾を置く専用候補は外したが、再帰展開の結果として先頭へ修飾が付くことは排除しない。
- `person_base`は終端語句だけに限定せず、循環参照を作らない組み立て定義も許容する。
- ステータス系10タグの`person_base(ally)`に`[tagSkill]の[skillPerson(ally)]`を追加した。`tagSkill`は対象Heroの最大保持数と既存の1・3・5・7個の段階から実スキル名を取得し、カギ括弧で囲む。属性系は対象外でdefaultは設けない。
- `skillPerson(ally)`は使い手・達人・名人・匠。一般の修飾人には混ぜない。
- 英語は対応する語句と語順を本番データへ実装した。敵名・スキル名は既存のゲームリソースを参照する。
- 本番の深さ12での終端候補優先と、異常時の展開10000回制限を備える。現行の定義に循環参照はない。シミュレータの通常生成には深さ制限を設けない。
