対象：`src/game/ShopSystem.js:81`〜`84`。接続先は`src/app/TrialSession.js`の`onItemPurchased`と`src/game/HeroItemInteractionController.js`の`addToWarehouse`。

2. 追加前タグ数1、生成済みタグ数2、宝石強化ありの購入品を5個用意する。
3. 配送先を`item => controller.addToWarehouse(item)`、統計コールバックをイベント収集に接続して`deliverSet`を呼ぶ。
