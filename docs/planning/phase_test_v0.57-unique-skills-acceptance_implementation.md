# 固有スキルの仕様受入テストと暴風の翼の演出

## 実装内容

- バージョン: `0.57.0`。`package.json`と`package-lock.json`を初回の実装開始時に更新した。
- `tests/spec/03.unique_skills.test.js`に36件の受入テストを追加した。
- 実際のBattleSystem・ChipBoard・Factory・装備・状態・移動処理を接続する。補助コードは`tests/spec/helpers/uniqueSkillsFixture.js`に置いた。
- 本番コードへテスト専用フックは追加していない。乱数・時間と初期装備を制御し、要求に記載された数値または独立した対照ケースから期待結果を求める。
- テスト対応表と検証範囲を`tests/README.md`へ記載し、対応したバックログの受入テスト整備項目を除いた。

## オーナー指定による追加範囲

- 暴風の翼はEnemyを対象に発動しないという指定に従い、要求03の対象とスタミナ条件の文言を整合させた。Enemy対応不足としてのバックログ登録は行っていない。
- 瞬間移動に見える演出を修正した。Heroは等倍のまま、倉庫の着地点へ移動しながら上昇する。影も移動する。
- 上昇の到達高さには通常登場時の`Chip.dropHeight`を使い、同じ重力から上昇時間を求める。上昇から落下への切替時にHeroの位置・高さを変更しない。
- 装備は最初からHeroと同じ位置・高さに表示し、そこから連続的に広げる。飛行中は描画用として扱い、倉庫への登録と通常の落下は頂点から行う。装備の落下開始高さは飛行時の高さを引き継ぐ。
- 散布の方向・距離に乱数でばらつきを持たせた。Heroから離して散らばらせ、倉庫の端でも装備が収まる着地点を選ぶ。
- 着地までは再装備・帰還を開始しない。着地後は既存のItemPickupControllerまたはFacilityReturnSystemへ渡す。
- `tests/manual/gust.html`に通常／1/4速度と帰還／再装備を切り替えられる確認入口を追加した。頭・胴・両手・足の全5装備を使用する。記録は保存しない。
- 要求03、実行時構成、固有スキル演出仕様、計画書、手動確認手順を指定内容に合わせて更新した。

## オーナー検証とフィードバック

- `OV-GUST-ASCENT-01`: Heroの等倍表示、上昇と着地点への移動、影の追従。最終修正の提示後、オーナーの`ok`により項目確認済み。
- `OV-GUST-DROP-02`: 装備の発生元から飛散・同時落下までの連続性。最終修正の提示後、オーナーの`ok`により項目確認済み。
- 影が元の位置に残り、倉庫へワープするという指摘に対し、上昇中に地上位置を移動する処理へ修正した。
- 確認画面の装備が3個だけという指摘に対し、全5装備のサンプルへ修正した。
- 落下地点が近い・均等に並びすぎという指摘に対し、距離を広げ、方向・距離に乱数を用いた。
- 上昇と落下の高さが異なるという指摘に対し、通常落下の開始高さへ上昇高さを合わせた。
- 装備が空中に突然現れるという指摘に対し、装備をHeroの位置から表示し、離れる過程から落下まで連続させた。周囲から表示を始めるオフセットをなくし、発生元と切替時の連続性の回帰テストを追加した。

- 既存バックログの他のオーナー検証は再依頼していない。
