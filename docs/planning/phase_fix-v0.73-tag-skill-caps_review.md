## 設計と動作の確認

- Hero・Enemyのタグ数は既存の `getEffectiveTagCount` で対応MAXと7までに制限され、スキル段階は表示と同じ `getTagSkillLevelForCount` を参照する。戦闘・ショップ・ギルドの既存の参照経路も維持されている。
- Collectorが同じ時点のタグ列とMAXから生タグ数表・有効タグ数表を作り、ラン・累積へ配信する。GameStatisticsはそれぞれの最高値を別に保持する。
- タグ実績の判定と所見は `effectiveTags` を参照する。二つ名もステータス系タグの寄与率とスキル語句に同じ有効値を使用し、属性タグの生タグ値は維持する。
- 初期・加入HeroはTrialStatisticsSession.attachHero、装備・解除や戦闘中の移送等はHero.refreshDerivedValuesを経由する。訓練はMAX更新直後に同じCollectorへ通知する。実セッションのTrainingSystemにもonStatisticsが接続されている。
- 過去の生タグ最高値と後のMAXを合成する処理はない。現在形式の保存・再読込で有効値を保持し、旧localStorage向け互換処理を追加していない。
