## 実装

- TitleMenuの仮レコードをRecordScreenへ置き換え、GameAppからRunRecordsRepositoryを接続した。
- ランキングは既存RunRankingsによる3基準・上位10件。達成日時を含む共通7列表、選択基準の強調、不合格の残り期限欄表示、終了時の順序を保持した顔のアップ画像を実装した。
- アチーブメントは全68件を定義順に表示。カテゴリ結合、判定、行動の判定基準、次評価までの数値と控えめなバーを表示する。最高判定は達成表示。
- 進捗目標は既存の評価式と同じ誤差許容値による二分探索で求める。新しい達成条件は追加しない。
- AchievementTableのrecordモードは5列。result・toastの形式は維持した。
- 課題記録は通常・エリート・ボスごとに最高クリアーレベル上位5構成。同一構成は1件で、未クリアーは除外する。
- 同レベルはその最高レベルの直近クリアー日時が新しい順、同日時は定義順とする。
- StageControllerがクリアー成立時に日時を一度取得し、StatisticsCollectorを通してラン・累積へ同じ日時を渡す。最高レベル更新・同レベル再クリアー時にhighestLevelClearedAtを更新し、低レベルのクリアーでは変更しない。
- 日時の欠落チェック、補完、旧記録向けの並べ替えフォールバックは設けない。オーナーの指示により、当初追加した欠落時の並び順補完を削除した。
- 日時は既存の保存時点で保存する。形式版1の構成別集計へフィールドを追加する。
- CroppedEnemyLineは実ゲームと同じcreateEncounterEnemiesで記録レベルの配置を生成する。実際の敵種・数・位置を6スロットで表示し、空き枠を保持、大型は2スロットとする。元画像を切り取らず、サイズ比と中心の高さを維持して表示する。
- レベルが課題進行で上がる旨だけを補足し、計算式・範囲は表示しない。記録がない種類には案内を表示する。
- 内部スクロール、日本語・英語、PC・スマートフォン縦横に対応する。タブと戻る操作を表の外側に確保した。
- タブ切替とEscapeで閉じる処理を実装した。ゲーム全体はGameAppで標準キー操作とフォーカスを抑止するポインター操作の設計であり、レコード画面からこの規則は変更しない。
- 課題選択画面への切り出し表示の適用は将来候補。GameWorksOAK・二つ名の選定は変更していない。終了画面の縮小表示と成績表の選定は追加合意に基づき変更した。
