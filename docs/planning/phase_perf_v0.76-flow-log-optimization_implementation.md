# フロートログ性能改善の実装報告

## 計画とオーナー指示

- 対象はPERF-01・PERF-05。バージョンは0.76.0。
- 当初はPERF-01を一時比較環境で確認してから通常反映する計画だった。
- 実装中にオーナーから「通常ダメージ・ミスは通常ソースに入れてください。実際のゲームで確認しないと、疑似的な表示では判断できません。」との指示を受け、通常ソースへ通知抑制を反映した。これは実ゲームで確認できる実装への指示であり、体験確認済みとは扱わない。
- 疑似表示による採否確認を取りやめ、通常の開発サーバーで実ゲームを確認対象とした。性能測定の人工ログ発行はCPU・フレームの技術比較だけに使用する。
- PERF-02〜04、保存形式、ゲーム内文言、共通リポジトリ、既存の保留検証6件は変更していない。

## 実装

- package.json・package-lock.jsonを0.76.0へ更新。
- CombatActionLogは通常ダメージ・ミスをnotify: falseで記録。勇者・敵の両方に適用し、会心・撃破の通知と全件の履歴を維持する。
- FlowLogで表示時間を決定し、既存の--flow-duration-adjustedへ渡す。getComputedStyleによる読戻しとCSSの基準時間・時間fallbackを削除。
- info・その他は6000ms、luckは9000ms、unluckは7000ms、system.warningは10000ms。hero/enemy.warningは6000ms。
- 0.85〜1.15倍の乱数補正、乱数消費順、battle/ex-skillの12〜44%とその他の56〜88%の位置、言語更新、主animationendでの削除を維持。
- ログ履歴仕様へ通知条件と表示時間を記載。確認済みのPERF-01・PERF-05をバックログから削除した。
- 比較・計測・一時ブラウザー検証はignore対象のtmp_flow_compare内。通常のVite設定からは読み込まない。

### 一時検証での失敗と修正

- サンドボックス内ではPlaywrightのブラウザー実行ファイルが見つからず、外側のブラウザーから内側のサーバーにも接続できなかった。通常環境で専用サーバーとブラウザーを起動して再検証した。
