## 実装結果

- `TrialSession`で初期Heroの参照を固定し、全員の`chip.isSettled`が成立したらゲーム画面の導入開始を許可する。既存の高さ・鉛直速度・移動・上昇の判定を使用するため、最初の接地で跳ね返りが残る場合は開始しない。
- 全員の着地完了はセッション内で保持する。後から加入したHeroや着地後の移動によって、初期着地待ちを再発させない。
- `TutorialController`へ開始可否のコールバックを渡し、`game-screen`の提供だけを制御する。シナリオID・既読・依存関係の判定は共通TutorialManagerに任せる。
- 着地待ちは停止理由を操作しない。課題選択を閉じた後は既存の更新ループで物理更新が進み、手動一時停止などがあればその停止を維持する。
- 手動確認用challenge-modeページも新しいコールバックを指定する。
- 要求01・チュートリアル仕様・テスト手順を更新し、対応済みのバックログ項目を削除した。
- 説明本文・ページ・ハイライト・カメラ演出・物理挙動とGameWorksOAKには変更を加えていない。
