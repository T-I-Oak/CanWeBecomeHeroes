# 開発バックログ

この文書は、次に着手する新規開発と、実装済みでオーナー確認を待つ作業だけを管理する。確定済みの仕様は `docs/requirements/`、実装済みの構造は `docs/specifications/` を参照する。

## 要望・バグ指摘

### ゲームランを完結させる

- eliteクリアー後の加入候補、選択、Hero追加を実装する。
- 期限切れによるゲームオーバー、7ステージ目のボス撃破によるクリアー、ラン結果の状態遷移を実装する。
- 出撃Hero選択、解放済みHero、セーブデータを入力とする本番開始状態へ、デモシナリオを置き換える。

### 戦闘とコンテンツを調整する

- タグ相性シミュレーションを基準に、アクションゲージ、ダメージ、敵HP、貢献ポイント、報酬、敵編成を調整する。
- 未設計12タグのelite・bossについて、固有スキル、名称、アセット、組合せを決定・実装する。
- 中・大Enemyのカタログ、名称、アセットを整備する。

### UIとゲームループを拡充する

- 進路を「課題」または「試験課題」へ変更し、進路選択のヘッダー表現も見直す。
- ピン止めした情報ウィンドウのサイズ切替、モバイル操作・カメラ、各エリアのビューを調整する。
- [時間設定]を設定（ギアアイコン）へ変更し、設定項目をモーダルダイアログで表示する。
- 速度バーの[標準]を、1.0倍の位置へ正しく配置する。
- シェア機能を実装する。共有する内容は別途検討するが、シェア機能自体は必須とする。
- ログ履歴、タイトル、説明書、結果画面、アチーブメント、チュートリアルを実装する。

### 記録と公開を整備する

- セーブデータ、解放状況、ゲームラン状態、統計、ラン結果、クリアー記録を永続化・表示する。
- `project_info.json` の紹介文・タグ・コンセプト画像を整備する。
- GitHub Pagesのビルド・デプロイ手順または自動化と、主要フローの受入テストを整備する。

### 共通開発ルールへの準拠を整える

- `GameApp`、`InformationWindowLayer`、`BattleSystem` の責務と依存関係を見直し、意味のある機能単位へ分割する。500行制限は、この分割が適切にできていることを確認する指標として扱う。
- `tests/spec/` に要求仕様と対応する受入テストを追加する。
- 仕様書の番号重複と、実装・テスト名に残る旧ターゲット選択表現を整理する。

## オーナー検証

### i18nと戦闘ターゲット選択

- 日英リソース、言語選択、情報ウィンドウ、ログ、戦闘ポップアップ、施設・進路表示をローカルで確認済み。
- 複数武器の順次候補絞り込み、宝珠の微小物理攻撃、旗の微小魔法攻撃、武器説明を実装済み。
- 公開先で `/data/game_text.json` の取得、言語切替、表示崩れのないことをオーナーが確認する。

### ポインタ基準ズーム

- ズームイン・ズームアウト時は、マウスポインタが示すゲーム画面上の位置を中心に拡大・縮小する。画面端でマップ外を表示できない場合を除き、操作対象がポインタ下に留まることをオーナーが確認する。
