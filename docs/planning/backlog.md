# 開発バックログ

## 次の本番実装

- デモシナリオを、ゲーム開始状態／セーブデータを入力とする本番シナリオへ置き換える。
- 7ステージのゲームランを実装する。加入イベント、期限切れ、ボス撃破時のクリアー判定を含む。
- 本番のゲーム開始処理を実装する。出撃Hero選択と解放済みHeroを開始状態へ反映する。

## デモ専用として残すもの

- ランダムHero・Item生成
- デモ用の戦闘経過tick計測

## 現在の仮実装・要調整

ここでは、動作する実装を置いているが正式仕様として確定していないものを管理する。各項目は、正式決定時に現在値を置き換えるか、実装範囲を広げる。未実装の将来機能そのものは、この節ではなく後続のバックログへ記録する。

- boss編成の出現数
  - 現在値: 全levelで、mainのボス1体、support1・support2を各2体とする（ボス1＋雑魚4）。これは標準フローのstage7を再現するための仮実装である。
  - 未決定: level上昇時のボス数・サポート数の増加式。6スロットを超える場合は、既定どおりmain（boss）→support1→support2の優先順で、入る範囲だけを配置する。
  - 更新箇所: `EncounterDefinitions` のboss難易度定義、敵編成・バランスの仕様、対応テスト。
- elite・bossの組合せ候補
  - 現在値: 活力系のみ。eliteはトレント／リビングアーマー／ピクシー、bossは歩く世界樹／リビングアーマー／ピクシー。
  - 未決定: 他14タグの中ボス・ボスの固有スキル、アセット、組合せ。
  - 更新箇所: Enemyカタログ、固有スキル定義、組合せ定義、情報ウィンドウ、対応テスト。
- 加入数とeliteクリアー後の処理
  - 現在値: `joinedCount` は進路抽選へ渡せるが、加入イベントとHero追加は未実装。
  - 未決定: eliteと加入候補の対応、加入演出・選択、加入数を更新する条件。
  - 更新箇所: StageController、ゲームラン状態、Hero初期化、進路・結果UI。
- 戦闘の基礎バランス値
  - 現在値: アクションゲージ増加量、物理・魔法の基本ダメージはrequirementsで暫定値として定義している。
  - 未決定: シミュレーション結果を踏まえた最終定数。
  - 更新箇所: BattleSystem、ゲーム設定仕様、シミュレーションの比較基準。
- 中ボス・ボスの名称・モチーフ
  - 現在値: 敵名称表の中ボス・ボスは、固有スキル設計の結果に応じて変更可能な候補として保持する。
  - 未決定: 各タグの最終名称・アセット・固有スキルの組合せ。
  - 更新箇所: 敵名称表、Enemyカタログ、アセット、情報ウィンドウ。
