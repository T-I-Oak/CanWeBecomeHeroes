# 開発バックログ

## 次の本番実装

- デモシナリオを、ゲーム開始状態／セーブデータを入力とする本番シナリオへ置き換える。
- 7ステージのゲームランを実装する。加入イベント、期限切れ、ボス撃破時のクリアー判定を含む。
- 本番のゲーム開始処理を実装する。出撃Hero選択と解放済みHeroを開始状態へ反映する。

## デモ専用として残すもの

- ランダムHero・Item生成
- デモ用の戦闘経過tick計測
