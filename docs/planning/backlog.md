# 開発バックログ

## 次の本番実装

- デモシナリオを、ゲーム開始状態／セーブデータを入力とする本番シナリオへ置き換える。
- スタミナ5以上のHeroにおける2個Item選択のUX・確定規則を定義する。1個目が行き先指定Itemで、別の通常Itemが存在しない場合は有効な2個目を指定できないため、出発してはいけない。選択取消、選択条件の案内、2個目が途中で消えた場合の扱いも合わせて決める。
- 戦闘・ショップ・ギルド・訓練のスロットを、確認用ガイドからゲーム状態と連動する表示へ置き換える。
- 戦闘・ギルドの到着後ゲーム処理を実装する。（ショップ売買・訓練は実装済み）

## デモ専用として残すもの

- ランダムHero・Item生成
- 追加ボタン
- 色付きの戦闘／施設スロット枠
