# 実装結果: 使い魔の色・アニメーション変更

## 計画に対する実装

- 既存の使い魔PNGは維持し、Canvas描画時の `grayscale(1) brightness(0.32)` で黒系に変更した。惑乱の画像・色・演出は変更していない。
- 周回速度を毎秒4から2.2ラジアンへ落とし、個体ごとに位相の異なる毎秒6回の横幅伸縮と、小さな上下動を加えた。
- 飛びかかりは発射時の表示位置を保存して始点とする。召喚直後の拡大途中の位置も使用し、飛行中の召喚元の移動に始点が引きずられないようにした。
- ダメージ・召喚条件・個数・攻撃相手の選択・被ダメージ時の消滅は変更していない。
- 初回実装のバージョンは、計画コミット時点の設定 `0.39.0` を使用する。package.jsonとpackage-lock.jsonはともに同じ版であり、設定変更は不要だった。タイトル・倉庫表示は共通のAPP_VERSIONを参照する。

## 変更箇所

- `src/game/CombatEffectSystem.js`: 黒系描画、羽ばたき、周回、固定始点の飛行。
- `src/game/CombatActionResolutionSystem.js`: 全個体の発射位置を取得後に周回表示を消去する順序へ変更。戦闘状態の消費は従来どおり攻撃開始時に行う。
- `tests/implementation/CombatActionResolutionSystem.test.js`: 召喚直後の発射位置、召喚元移動後の始点固定、飛行終了を検証。
- `docs/specifications/09.unique_skill_presentation.md`: 確定した描画と動きを反映。
- `docs/planning/backlog.md`: 対象要望を実装済みの説明へ変更。
