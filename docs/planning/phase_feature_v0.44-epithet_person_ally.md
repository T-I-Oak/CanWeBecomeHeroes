- 各情報種別に1候補ずつ提示する相談用の案。まだ採用済み定義ではない。
- ゲーム内の職業名「剣士・衛兵・魔法使い・僧侶・盗賊・狩人・商人・交渉人」は使用しない。
- 固定語句は単独で呼び名として使えるものを選ぶ。修飾が必要な語句はqualifiedPersonと分ける。
- 旧語句リストは参考資料としてのみ参照し、本表の案を自動的に確定扱いしない。
- 不採用語句や一時的な不足の個別記録は残さない。

## 候補の確認

- 聖印「聖人」と試験場への出発回数「英傑」はオーナー了承済み。弓「スナイパー」はオーナー提案を反映した仮候補。
- 漢字の呼び名に限定せず、カタカナ等も含めて候補を広く考える。
- 武勇のperson(ally)はオーナー提案を反映し「キラー」を仮候補とする。同じ情報種別のactionPerson(enemy)にも「キラー」があるが、前者は単独の呼び名、後者は敵名の後ろへ連結する表現として用途が異なる。

- 軽業「韋駄天」の英語表現は、オーナーとの相談によりSpeed Starとする。日本語の語構成をそのまま英語へ直訳せず、二つ名としての印象を合わせる。
- 追加候補「麒麟児」はオーナー提案。情報種別への配置は未決定。汎用のperson(ally)へ置く案を提示する。

- 布の「名匠」、雷の「風雲児」、軽業の「韋駄天」、信用の「雄弁家」はオーナー提案・評価を反映済み。ほかの候補は引き続き相談用の案。
- 普通の職能名を並べるのではなく、授けられて嬉しい格・特別感・卓越性のある呼び名を重視して見直す。強さは戦闘に限定しない。

- 32情報種別を一覧化し、現在の候補を記載する。「—」は候補を見直す欄。除外した語句の履歴は残さない。
- ゲーム内の日本語職業名との完全一致・含有を確認する。
- 語句の完全一致で重複を確認する。
- 似た職能や表現のイメージは、オーナーと相談して調整する。
- 既に定義された敵のperson(ally)構成と、情報共通の再帰構成は本表とは別に保持する。
