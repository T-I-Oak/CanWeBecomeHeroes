## 照合結果

- GameLogを唯一の記録元とし、notify: falseを含む現在ランの全件を保持する。履歴表示・フィルター変更は記録を変更しない。
- 通常ダメージ・ミスは構造化キー、Exスキル専用19種はex-skill channelで分類する。通常攻撃の会心・撃破を保持し、FlowLogの戦闘表示位置も維持している。
- 静的参照は共通のLogMessageView・createLogMessagePartsで描画し、情報リンクは既存Manager・Treeへ親IDと定義参照を渡す。
- 履歴の移動・ピン止め・拡縮・停止理由・親子閉鎖は既存の情報ウィンドウ機構に従う。ラン終了時に履歴と購読を破棄する。
- 仮想スクロールは表示範囲と周辺のみを描画し、行高を実測する。初回・再表示時の末尾移動、新着追従、過去閲覧中の位置維持、再描画時の位置復元を確認した。
- フィルター初期値と保存は共通DataManagerのgetSavedData・setSavedDataに統一されている。機能側に独自のデータ補完・変換処理はない。
- アチーブメント記録は統計セッションの構築前に接続され、通知項目ごとのIDと到達判定を保持する。silent記録、複数通知、言語変更による再解決と非破壊性をテストで確認した。
- 設定入口はタイトル・ゲーム共通のギアへ移り、言語ラベル、ツールチップ、safe area、押下・ホバー反応、動き低減設定に対応する。劇を情報ウィンドウより前面にする変更はオーナー指示と一致する。
- 関連仕様・構成・バックログは実装内容と一致する。使い魔のダメージ確認と終了時成績表の表示優先順位は対象外としてバックログへ記録されており、今回実装されていない。
- 共通ルールには01.branch_workflow.mdの実験適用規定を優先した。GameWorksOAKの作業ツリーはクリーンで、レビューでは変更していない。
