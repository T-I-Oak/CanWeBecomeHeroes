元のチェック項目の出現順で `CC-節.連番` を付与。親・下位項目も独立行にし、項目文は原文を保持する。
規定の参照元は各節見出し。各根拠はゲームルート基準のパスで、実行結果は [実装報告](phase_chore_v0.78-pre-release-audit_implementation.md)、指摘は [指摘一覧](phase_chore_v0.78-pre-release-audit_findings.md) を参照する。
「未確認」は証拠不足を評価した結果であり適合を意味しない。「適用外」は段階・条件外を意味し、将来操作の確認を省略しない。
