# 開発計画: tag_badge_layout

## 開発スコープ
- モバイル画面における、HeroおよびEnemyの情報ウィンドウのタグバッジ列レイアウト調整。
- タグバッジ列を全体でステータスバー7本分の列幅に揃える。
- 通常タグ5列は左側のステータスバー5本と各列で対応させ、幅を合わせる。
- Exタグバッジは右側のステータスバー2本分の領域に配置する。
- Exタグがない場合でも右側2本分は空白として確保し、通常タグ5列を広げない。
- 情報ウィンドウの横幅が広がった際にも、この列対応と比率を維持して通常タグとExの幅を調整する。

## 対象外
- タグバッジ列およびステータスバー以外の情報ウィンドウ内要素のレイアウト変更。
- チュートリアルの実装（別タスクで実施）。
- 各タグの機能自体や、ステータスの計算ロジックの変更。

## 完了条件
- HeroおよびEnemyの情報ウィンドウで、通常タグが左から5列分（ステータスバー5本分）、Exタグが右側2列分（ステータスバー2本分）の領域に配置されていること。
- 情報ウィンドウの幅が変わっても、タグバッジとステータスバーの幅の対応関係が維持されること。
- Exタグの有無にかかわらず、通常タグの領域幅が広がらず、意図した配置が維持されること。

## 実装・テスト方針
- 情報ウィンドウのレイアウトを管理しているスクリプト（`InformationWindow` またはそれに紐づくレイアウトクラス）を特定し、タグバッジのコンテナおよび各バッジのスタイル計算を修正する。
- CSS/Grid や Flexbox の比率（例えば 5:2 や 1fr x 7 など）を利用して、ステータスバーとタグ列が視覚的に揃うように調整する。
- ローカル環境およびテストにて、情報ウィンドウの表示テスト（特にモバイル幅での確認）を実施し、レイアウト崩れがないことを確認する。
- UIレイアウトのテスト（あれば）を実行・更新し、全テストと本番ビルドがパスすることを確認する。
