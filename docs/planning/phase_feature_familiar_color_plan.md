# 計画: 使い魔の色・アニメーション変更

## 開発スコープ
- 惑乱アイコンと混同しないよう、ドラキュラの「夜の使い魔」の色をコウモリらしい黒い色合いに変更する。
- 動作の見やすさ改善のため、使い魔のアニメーションの見直しを行う。

## 対象外
- 使い魔の仕様（ダメージ、行動ロジック、召喚条件など）の変更。
- 惑乱アイコンの変更。

## 完了条件
- 画面上で使い魔の色が黒系に変更され、惑乱アイコンとの見分けが明確になること。
- アニメーションが適切に再生されること。

## 実装・テスト方針
- 使い魔の描画処理（SVG等）およびCSSアニメーション定義を調査・修正する。
- ローカルプレビューで見た目と動きを確認する。
- 修正完了後、対象テスト・全テスト・本番ビルドを実行して影響がないことを確認する。
