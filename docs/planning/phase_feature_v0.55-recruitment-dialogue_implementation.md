# Hero加入会話の実装報告

## 計画に対する実装

- バージョンを `0.55.0` に設定した。
- 一般用48件・知人用24件の日本語を計画書の確定稿に合わせ、同じ意味・人物像の英訳を定義した。72件の日本語と計画書の表の一致を実装時に照合した。
- `RecruitmentCast` は4組の知人関係を定義し、2人PartyではB、3人PartyではCを知人にする。残る人物は既存の戦闘スロット順・準備枠順で割り当てる。
- `TrialSession` から配役と知人の有無を明示的に渡し、`RecruitmentVignetteScenarios` で登場・誘い・承諾だけを切り替える。一般用と同文の知人台詞も独立して定義した。`GameTextRepository` は既存の厳密な取得処理を使い、知人用から一般用へのフォールバックは設けていない。
- A→B→X→B(C)→X→Aの6発言と演出、加入確定・次課題進行を担当する既存処理は維持した。開始劇と戦闘バランスは変更していない。
- 加入劇仕様と人物設定資料を更新した。人物設定資料に無属性の魔法攻撃と炎・水・雷の属性軽減の区別を明記した。
- バックログから整備済みの紹介情報、調整不要と判断済みの使い魔威力・戦闘時間・試験難易度、今回対応した加入会話の検討項目を削除した。既存の保留オーナー検証は維持した。
- `tests/manual/recruitment-dialogue.html` に本番の配役・シナリオ・描画を使う確認入口を設けた。本番ビルドには含まれない。操作手順は `tests/manual/README.md` に記載した。
