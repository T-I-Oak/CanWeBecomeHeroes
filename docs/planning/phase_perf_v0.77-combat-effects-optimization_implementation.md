## 画素・読み込み・画質の自動確認

- 雷単独: 1280×900の同一Canvas、同じ時刻0.1秒・座標・decode済み画像で旧→変更→旧を比較。ウォームアップ後の画素差0、旧同士の差0。通常コンテキストとwillReadFrequently指定の双方で一致。
- 最初の性能ページで初回描画直後に比較した際には雷単独に6画素の差が出た。初回差の原因は断定せず、ウォームアップ後・旧同士の再現性も確認する独立検証へ切り替えた。初回値を一致の根拠には用いない。

- 採用使い魔と旧画像はともに1254×1254。alpha>16の外接矩形は旧[11,261,1245,957]、採用[13,260,1246,959]。外形は完全な画素一致ではなく原寸で1〜2pxの差がある。位置・透明余白・ポーズは画像案で、動きはOV-PERF-03-MOTIONで確認済み。
- DPR 3・zoom 1.5・大型の布の敵・付与値7の描画を実ブラウザーで確認。ページの実行時エラー0。必要寸法を段階が満たさない場合は元画像を使う。画質の十分性を自動確認だけで承認済みとはしない。
