# タッチドラッグ中のルーペ表示 実装報告

## 対象

- ブランチ: `feature/v0.71-touch-drag-loupe`

## 実装結果

- `GameCanvasInput`は開始時のpointerTypeを保持し、タッチでドラッグ選択と選択基点が有効な間だけCSS pxの指位置を返す。対象上へ重なることは表示条件に含めない。
- 新設`TouchDragLoupe`は指周辺を2倍、最大160×128 CSS pxで表示する。中央照準と切り出し中心を一致させ、画面端の配置補正は入力へ戻さない。
- 指から36px、画面端から8pxを基準に上側へ配置し、上に入らない場合は下側へ切り替える。上へ戻す境界には24pxの余裕を設ける。
- `TrialSession`は通常表示と共通の`drawWorld`・`ChipRenderer`・方向表示描画器を使い、ルーペ倍率×画素密度の変換を設定した小さなCanvasへ再描画する。内部画素とCSS pxの実寸比率を各軸で使用し、元の画面外はクリップして背景色とする。盤面の縮小済み画素を拡大する方式は廃止した。
- 小さなCanvasとルーペ用描画器はタッチ選択の初回だけ生成し再利用する。同じ時刻・Chipの描画順序を使用し、ゲーム状態や演出時間を追加更新しない。銘板レジストリーは入力用と分離し、ギルド時間軸の追加描画結果は状態へ反映しない。入力を遮らない方向表示Canvasへ等解像度で合成する。
- 終了・キャンセル・キャプチャ喪失・ピンチ開始・選択基点解除で表示を終える。マウス・ペン・タップ・空白からのパンでは表示しない。
- 要求02、ランタイム仕様、テスト案内、手動確認手順を更新した。対象の要望をバックログから除いた。未回答の実機確認は保留扱いでバックログへ追加していない。
- GameWorksOAKへの変更はない。
