# 実力判定試験の実装報告

## 計画に対する実装

- バージョンは初回実装の `0.51.0`、終了草案へのフィードバック修正で `0.51.1`、回転中のクリッピング修正で `0.51.2`。ブランチは `feature/v0.51-challenge-mode`。
- GameAppからモードを共通のメンバー選択・開始劇・TrialSessionへ渡す。RunControllerはchallengeで第7課題を越えて継続し、延長込みの残り期限が尽きるとcompletedで終了する。敵・難易度・報酬・加入上限の計算は変更していない。
- GuildPanelは7課題単位で紫系と赤系を左から塗り替える。課題番号の位置と通常試験の表示を維持した。
- 専用チュートリアルはchallenge-selection-intro。承認済み3ブロックを3ページで表示し、先行条件なしで課題選択時に開始する。通常試験用シナリオとモードで分離し、既読・リセットは共通基盤を使用する。
- challenge-noticeは到達課題番号・二つ名付き終了メンバー・判定日・発行者を表示する。「試験終了」の後に大きな透明な紙が縮小して現れ、紙吹雪・署名・印を表示しない。裏面・表裏操作・タイトル復帰は共通機能を使用する。
- TrialStatisticsSessionでモード固定を解消した。challengeのcompletedを試験合格・不合格へ加算せず、開始・終了回数をモード別に保存する。到達番号と実際のクリアー数を区別し、二重終了・保存再試行による再集計を防ぐ既存構造へ接続した。
- RecordScreenに実力判定試験タブと4順位基準を追加した。勇者認定試験の合格状況でタブを解放し、ランキングデータの存在では代用しない。経過時間を表示し、日英のタブラベルはランキングを省略する。
- 日英リソース、ゲームラン・記録・通知・チュートリアル・表示規約を更新した。対象の実装済みバックログ項目を除いた。オーナー確認が未回答の項目はバックログへ保留扱いで移していない。
- `tests/manual/challenge-mode.html` を追加した。本番クラスをメモリ上だけの表示サンプルへ接続し、課題境界・4人通知・チュートリアル・ランキング解放前後を確認できる。通常の本番ビルドへは含めない。

本番の実装クラスを使用した4人の終了通知と手動確認ページも動作し、pageerrorは0件。通知は第8課題到達、ランキングは7課題クリアー・8日0時間を表示した。

v0.51.1では、紙とボタンを中央にまとめ、紙の直下へ操作部を配置した。日英・1280×720／390×844／844×390で紙下端とボタン上端の間隔が0～24px以内であること、表裏操作と復帰をブラウザで検証し、全6条件で成功した。ボタンの操作高と紙面の独立した縮小を維持した。

v0.51.2では、1280×720／390×844／844×390で往復の回転途中を45度で静止して確認した。紙面から最外枠までの内側祖先3要素はすべてoverflow:visibleで、遠近法で内枠を越えた上下の紙面が表示される。スマートフォン縦画面の静止画像でも上下の斜辺が切れないことを確認した。画面そのものを越えた部分は最外枠で切り取る。ブラウザのpageerrorは0件。
