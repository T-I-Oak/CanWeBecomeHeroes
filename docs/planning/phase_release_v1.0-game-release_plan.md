# v1.0 正式公開計画

## 合意事項

- オーナーの公開指示に基づき、現在のv0.81.1を基に正式公開する。
- オーナーはMajorをv1へ更新すると明示した。予定バージョンは1.0.0とする。
- ブランチは `release/v1.0-game-release`。起点はmasterの `c59366f`。
- 公開バッジの強調終了日は2026年12月31日（`featuredUntil: "2026-12-31"`）とする。当日を含む。

## スコープ

- 実装開始時にpackage.json・package-lock.jsonを1.0.0へ更新し、タイトルと倉庫左下の表示を一致させる。
- 利用者向け更新履歴を1.0単位で整備する。日付は実際の公開日とする。
- ゲーム本体の検証とデプロイ結果を確認し、公開URLで主要操作・素材・バージョン表示を確認する。
- 本体の公開確認後、project_info.jsonのボタンをpublishedへ切り替え、公開日とv1.0を示すバッジおよび合意済み強調終了日を設定する。
- ポータルで紹介表示、ゲームへの遷移、更新履歴を確認する。

## 対象外

- 新機能、ゲームバランス変更、既存ゲーム内文言の改稿。
- v0の保存データの移行・補正・旧評価維持。
- GameWorksOAKの変更、ポータル一覧の編集。

## 完了条件

- バージョン設定とタイトル・倉庫の表示が1.0.0で一致する。
- 対象テスト、全テスト、ブラウザー検証、本番ビルドの結果が記録され、失敗がある場合は原因と対応が明確である。
- 必要なオーナー検証について、一意ID、判断、対応、明示保留が記録されている。
- 対象コミットとデプロイ結果が一致し、公開URLで対象版の主要操作・素材が確認できる。
- ポータルが公開中を示し、ゲームへ遷移でき、更新履歴と公開バッジが表示される。
- バッジの強調終了日が2026-12-31である。

## 実装・検証方針

- docs/planning/01.branch_workflow.mdおよび共通のゲーム公開手順・フェーズ作業手順に従う。
- 公開先は https://t-i-oak.github.io/CanWeBecomeHeroes/ とする。
- 既存のmaster push起動のGitHub Actionsを使用する。ゲームと公開済み共通masterをビルドし、distをgh-pagesへ配信する構成を確認する。
- ローカルのポータル一覧には登録済み。公開環境の表示と取得結果は別途確認し、ローカルの登録だけで公開確認済みとは扱わない。
- ゲーム内文言を変更する必要が生じた場合は、変更箇所と修正前後の全文を提示し、合意後に反映する。紹介文言・更新履歴の具体案も実装時に提示する。
- バージョン・公開データの既存テストを確認して対象テストを選び、npm.cmd test、npm.cmd run test:browser、npm.cmd run buildを実行する。
- 実装報告に各コマンドと結果、失敗調査、オーナー検証を記録する。公開環境の確認をローカル検証で代用しない。
- 本体の動作確認後に公開中メタデータを配信する順序を守る。masterへの配信が必要な検証は、実装時に実施可能範囲と公開後の確認手順を記録し、マージ前の確認と混同しない。
- 公開後にメタデータ更新が必要となる場合も、実装・レビュー・マージの手順を適用する。マージ中にソースやメタデータを修正しない。
- マージ着手前とpush直前に共通ライブラリの公開状態を所定の6コマンドで確認する。共通側の問題はオーナーへ報告する。
- 公開が別日になる場合は実際の日付をバッジと履歴へ用い、合意済みの強調終了日は維持する。
