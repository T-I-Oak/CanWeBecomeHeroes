## 実装

- `npm.cmd version 1.0.0 --no-git-tag-version`によりpackage.jsonとpackage-lock.jsonを1.0.0へ更新した。
- タイトルと倉庫のバージョン表示は既存の共通取得経路を使用する。表示コードの変更はない。
- 更新履歴1.0を種別new、日本語「初版リリース」、英語「Initial release」で追加した。日本語と種別はオーナー指定。英語は指定内容に合わせた。
- project_info.jsonは本体の公開確認後に切り替えるためpendingを維持している。

## 公開環境の確認手順

- この実装でゲームのmasterへのマージ・pushは行っていない。
- 既存Actionsはmaster pushを起点に共通masterをcheckoutし、テスト・ビルド後にdistをgh-pagesへ配信する。
- マージ時に共通ライブラリの公開状態を所定の6コマンドで確認する。
- 対象コミットのデプロイ成功を確認し、公開URLで入口・主要操作・素材・バージョンを照合する。
- 本体の動作確認後、公開中メタデータを実装・レビュー・マージの規約に従って反映し、ポータルの表示と遷移を確認する。
- 公開先の実動作とポータル確認は未実施であり、ローカルの成功を公開確認済みと扱わない。

## オーナー検証

変更はバージョン設定と指定済みの更新履歴であり、ゲーム機能や画面の変更はない。設定・画面表示・履歴の整合は自動検証とスクリーンショットで確認し、追加のオーナー操作確認項目は設けていない。
公開用文言はオーナーへ提示し、更新履歴の日本語と種別について修正指定を受けて反映した。
公開後の実動作・ポータル確認は未実施の公開作業であり、オーナー保留としてバックログへ追加しない。
