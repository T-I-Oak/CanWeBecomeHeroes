# ログ履歴ウィンドウの実装報告

## 対象と設計合意

- ブランチ: feature/v0.48-log-history。初回バージョン: 0.48.0。オーナーフィードバック反映後のバージョン: 0.48.3。
- オーナーと合意した情報ウィンドウ形式、既存のピン止め・拡縮・停止制御、PaperScroll、フォーカスを残さない操作を使用。
- 通常ダメージ・ミスとExスキルの2スイッチを追加。現在のランの全ログを保持し、描画範囲を限定する。
- HUDの設定をログ履歴へ置換し、設定をタイトル・ゲーム共通の右上ギアへ移動。
- 使い魔のダメージが低すぎる可能性の確認をバックログへ追加。バランス調整は行っていない。

## 実装内容

- InformationWindowLayerとTreeにlog-historyを追加。既存Manager・操作部品で寿命・親子関係・停止設定を管理する。
- LogHistoryPanelはGameLogの全記録を表示条件で抽出し、VirtualLogListへ渡す。独立したログ記録台帳は作らない。
- VirtualLogListは可変行高の累積高さから表示範囲を選び、本文のDOM数を制限する。末尾追従、過去閲覧中の位置維持、最新への移動、再表示時の末尾移動を実装。
- LogMessageViewに静的情報リンクの描画オプションを追加し、フロートと文言・アイコン解決を共用。
- AchievementLogで既存達成通知をGameLogとトーストへ接続。IDと到達判定を保持し、notify: falseとして履歴だけに出す。構築中のrun-start通知も対象。
- Exスキル専用19種をex-skill channelへ分離。FlowLogはbattleと同じ配置範囲を利用。
- 仕様19.log_history.md、構成、UI規定、停止理由、達成通知仕様と計画書を更新。履歴実装項目をバックログから除いた。
