# アチーブメント取得トースト実装報告

## 実装内容

- バージョンを0.45.0へ更新。
- 右下固定の見出しとテーブルをAchievementToastへ実装。行は共通DOM生成のtoastモードから追加する。
- 旧判定（未達成はE）の黒字表示、拡大、赤い最新判定への切替、通常サイズへの復帰を実装。
- 行ごとの寿命、末尾追加、行の伸縮、最後の行と見出しの縮小、表示高さに応じた待機列を実装。同じ項目の別タイミングの通知も別行とする。
- ラン開始・初期Heroの接続前に通知を接続。保存済み評価の再通知を防ぎ、表示から保存・集計を再実行しない。
- モーダル・チュートリアル中は隠して演出・寿命を停止。結果表示・タイトル復帰時は破棄する。
- 通常項目の通知段階を15段階へ変更。所見・評価式・保存形式は変更しない。複数段階を越えた場合は最終判定だけを通知。
- 日本語・英語の見出し、既存の評価項目リソース、モバイルのsafe areaと折返しへ対応。
- 仕様18を追加し、仕様14・バックログの実装範囲を更新。

## 合意したUI

オーナー提案の右下・下端固定・複数行テーブルと、コンテナ・エントリの個別演出を採用。細分段階を通知し、多すぎる場合は目標調整を第一に検討する。同じ項目の別タイミングの達成は新しい行を追加する方針で合意した。

時間は伸縮250ms、判定変化600ms、その後3秒保持。終了画面と同じ倍率で全体を拡縮し、拡縮後の高さ30％を目安に待機列へ送る。モーダルから戻ったら停止位置から再開する。
