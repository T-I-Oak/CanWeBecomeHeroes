# 卓越した人の呼び名：検討用サンプル

呼び名を先に集め、意味・印象に合う情報種別へ配置する。以下は提案であり、語句定義へまだ登録しない。配置欄は辞書的な意味から考えたゲーム用の案で、確定ではない。

| 呼び名 | 意味・印象 | 配置の案 |
| --- | --- | --- |
| 鬼才 | 並外れた独創的な才能 | 魔導、宝珠 |
| 異才 | 人と異なる際立った才能 | タロット、情報共通 |
| 神童 | 幼い頃から非凡な才能を持つ人 | 麒麟児と比較して検討。年齢の印象あり |
| 英傑 | 才知・力量の優れた人物 | 武勇、試験場 |
| 豪傑 | 豪胆で力強い人物 | 武勇、鉄 |
| 傑物 | 並外れた能力を持つ人物 | 情報共通 |
| 怪傑 | 不思議なほど優れた力を持つ人物 | 爪、情報共通 |
| 達人 | 一つの道を極めた人物 | 訓練場、武器全般 |
| 名人 | 技芸に抜きんでた人物 | 弓、軽業 |
| 名手 | 特に技量が優れた人物 | 剣、盾、弓 |
| 巨匠 | 一分野で際立った成果・技量を持つ人物 | ショップのタグ追加、布 |
| 大立者 | 一分野の中心となる有力な人物 | ギルド、旗 |
| 千両役者 | 高く評価される役者。転じて見事に活躍する人物という印象 | 軽業、幸運 |
| 鉄人 | 非常に頑健で、卓越した力・能力を感じさせる呼び名 | 鉄、活力、訓練場 |
