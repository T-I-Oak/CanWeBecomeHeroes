# チュートリアルの実装結果

## 実装内容

- バージョンは0.38.1。初回の終了草案後にリセットの完了フィードバックを追加する指示を受けたため、Patchを更新した。オーナーとの打ち合わせで確定したシナリオ・文面を`docs/specifications/10.tutorial.md`へ記録した。
- `public/data/text/tutorial.json`に日本語・英語の8シナリオ、24ページ、triggerとrequiresを定義した。試験場・ショップ・ギルド・訓練場は並列で、すべての完了後に設定の説明へ合流する。
- `TutorialController`を追加し、共通ライブラリのTutorialManagerへタイミング、対象範囲、カメラ演出、独立した停止理由、DataManagerへの保存を接続した。依存関係・完了判定・ページ進行は共通ライブラリが担う。共通ライブラリのソースは変更していない。
- 対象なしの説明は中央表示。対象ありの説明は共通ライブラリの位置調整と矢印を使用する。本文だけをスクロールし、タイトル・ページ番号・次へボタンを常に表示する。空行を通常の改行へ詰め、低い画面ではボタンと余白を小さくした。
- 準備エリアは現在のパーティー人数分を対象とする。チュートリアル中はHUDを隠し、HUDがハイライト対象の場合と終了後に表示する。
- 通常カメラのリサイズ時は表示中心を可能な限り保ち、範囲を超える場合だけ補正する。チュートリアル中は対象へのパン・ズームを再計算し、終了時は保存した通常カメラに既存のsetViewportを適用して復元する。復元演出中のリサイズにも追従する。
- 設定のリセットボタンを接続した。押した直後には案内せず、次の課題選択から再開する。
- リセット処理中はボタンを無効化し、完了時に設定内へ「チュートリアルの進捗をリセットしました。」と表示する。次に設定を開く際はメッセージを消す。
- 表示上のスタミナ単位に合わせ、案内と既存のエリア・施設説明を300表記へ修正した。内部の条件値3は維持する。
