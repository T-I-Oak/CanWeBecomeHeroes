- タグは既存の動詞案を引き継ぐ。武器・施設は今回の追加案。件数を埋めるための無理な追加はしない。

- 既存の句はそのまま引き継ぎ、シミュレーションで接続や表現を確認して調整する。
- 不採用語句の履歴や個別の不足記録は残さない。

- 語句の完全一致による重複をチェックする。
