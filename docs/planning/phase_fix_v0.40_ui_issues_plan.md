# 開発計画 (fix/v0.40-ui-issues)

## 開発スコープ
- 惑乱状態が解消しても惑乱エフェクトが残り、戦闘離脱後も表示され続ける不具合の修正
- 課題選択のキャラクター画像が粗くなる表示の改善（Canvasの描画解像度の最適化）

## 対象外
- 今回の修正に関連しないバックログ項目
- その他の新機能追加

## 完了条件
- 惑乱状態が通常解除・撃破・課題移行などで解除・リセットされた際に、チップに残る惑乱エフェクトが正常に消去されること。
- 課題選択画面におけるキャラクターのCanvas描画が、端末のピクセル比(`devicePixelRatio`)に合わせて高解像度で行われ、表示が粗くならないこと。
- 全てのテストがパスし、本番ビルドが正常に完了すること。

## 実装・テスト方針
- **惑乱エフェクト残留の修正**: `CombatConditionSystem.reset()` および関連する解除処理（`clearBewilderment` など）を調査・修正し、状態データのリセットと同時に、画面上のチップ(Chip)から惑乱エフェクトクラス等の表示要素が漏れなく消去されるようにする。
- **画像の解像度改善**: `StageSelectionModal.createEnemySlot()` におけるCanvasの生成・描画処理を見直し、描画サイズ（width/height属性）には実際のピクセルサイズ（表示サイズ × devicePixelRatio）を設定しつつ、CSS側で表示上のサイズを制御することで高解像度対応を行う。
- **テスト**: 修正内容に関する単体テストを適宜修正・追加する。複雑なロジック（特に惑乱状態のリセットや状態管理）に対しては、TDD（テスト駆動開発）の原則を必須とし、実装前にテストを作成して仕様を定義する。実装完了後に全テストスイートおよび本番ビルドを実行し、既存機能に影響が出ていないことを確認する。
