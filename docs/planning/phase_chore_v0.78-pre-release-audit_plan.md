# V1公開前の臨時総点検計画

## 目的

V1公開予定を控え、10回ごとの定期見直しとは別に、現時点のゲーム全体について共通ルールへの準拠とレビューチェック項目を総点検する。

## 合意した開発条件

- ブランチ: `chore/v0.78-pre-release-audit`
- 予定バージョン: `v0.78.0`
- 計画時の基準: `master` の `76ee014`、設定バージョン `0.77.1`。
- バージョン設定は初回の実装開始時に更新する。
- 点検と報告書作成を行い、発見した修正事項は一覧を提示して対応範囲を相談する。

## スコープ

- GameWorksOAKの共通ルール一式と、このプロジェクト固有ルールへの準拠を確認する。
- `99.compliance_checklist.md` の全項目を点検する。親項目・下位項目を取り落とさず、参照元の規定と照合する。
- 文書、ソース、CSS、モバイル対応、共通ライブラリ利用、テスト、アセット、公開設定を対象とする。
- 要求・仕様・実装・テストの整合、未使用コード、ファイル規模、責務と配置、参照切れ、重複実装を確認する。
- バックログ、保留中のオーナー検証、確認可能なフェーズ運用の記録を照合する。
- 公開準備・公開手順を参照し、公開前の不足事項を抽出する。

## 対象外

- 機能追加、ゲームルール変更、指摘事項の無断修正。
- V1へのMajor更新、公開操作、公開中へのメタデータ切替。
- 共通リポジトリの変更。必要な変更は問題と根拠を報告する。
- オーナー保留項目の独断による確認済み扱い。
- 実機未確認事項や、過去の記録で裏付けられない事項の適合扱い。

## 点検・報告方針

- チェック項目ごとに一意の識別子を付け、規定、対象ファイル・箇所、確認方法と根拠を対応付ける。
- 判定は「適合」「要対応」「適用外」「未確認」とする。適用外には理由、未確認には不足する証拠や確認手段を記載する。
- 公開時やマージ・push時に実施する項目は、現段階の準備状況と、実操作時に残る確認を区別する。
- 指摘には重要度、具体的な事象、根拠、公開への影響、推奨対応を記録する。
- チェックリストの形式的な一致だけでなく、参照元の例外・適用条件・設計意図を確認する。
- 機械的検索、実装の読解、自動テスト、ブラウザー確認を組み合わせる。自動検証の成功だけで全項目を適合としない。
- 報告が肥大化する場合は、項目別の点検表と指摘一覧を意味の区切りで分割し、`phase_` 成果物として管理する。
- 修正が必要な場合はオーナーへ一覧を提示し、対応範囲に合意してから着手する。計画変更が必要なら再合意を得る。
- ゲーム内文言の変更が必要な場合は、反映前に箇所と変更前後の全文を提示して合意を得る。

## 実装・テスト方針

- 実装開始時に `package.json` と `package-lock.json` を `0.78.0` へ更新する。
- 計画で許可する変更はバージョン設定と点検成果物の作成を基本とする。
- 共通ルールの正式な状態を確認し、共通側の未コミット変更を正式適用済みの規定として扱わない。
- `tests/README.md` と `tests/02.browser_verification.md` に従い、全テスト、本番ビルド、既存ブラウザー検証を行う。
- 全テストは `npm.cmd test`、本番ビルドは `npm.cmd run build` を実行する。
- ブラウザー検証は既定の専用サーバーとプロセス管理手順に従い、実行コマンド、結果、後処理の確認を記録する。
- 追加で必要な対象検証は点検内容に応じて実行し、コマンドと結果を実装報告へ記録する。
- 失敗は原因を調査し、今回の変更、既存の問題、環境による未確認を区別する。
- 実機Safari等、自動検証で保証できない事項は明示する。必要なオーナー検証には一意ID・理由・操作・期待結果・確認バージョンを提示する。
- オーナー確認時にはタイトル・倉庫左下の表示と設定のバージョン一致を確認条件とする。

## 完了条件

- 共通チェックリスト全項目の判定と根拠が記録され、未評価項目がない。
- 共通ルールと固有ルールの点検範囲が明確で、主要な要求・仕様・実装・テストの整合を確認している。
- 全テスト、本番ビルド、既存ブラウザー検証の結果と、失敗があれば調査結果が記録されている。
- 公開前に解消すべき事項、残る確認事項、対応範囲の相談が必要な指摘が一覧化されている。
- 必要なオーナー検証の判断とフィードバック対応が記録され、未回答を独断で保留していない。
- 実装報告が計画と点検成果物を対応付け、その後のレビューで網羅性と判定根拠を照合できる。
