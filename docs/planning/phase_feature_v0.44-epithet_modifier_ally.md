## ねらい

- タグスキル名の「一撃必殺」「大賢者の秘術」「盗賊の極意」「不動の構え」「守護結界」「疾風の残像」「天運の寵児」などを参考にした。
- 施設系は試験場「歴戦の」、訓練場「屈強なる」、ショップへの出発回数「黄金の」、ギルドの期限延長時間「不退転の」をオーナー提案・評価として反映した。その他も直近の案で一覧更新する指示に従って反映した。
- 各語句をあらゆるpersonへ接続した際の自然さを厳密に保証するものではない。お楽しみ要素としての組み合わせを、候補を相談した後のシミュレーションで確認する。
- 情報共通・defaultのmodifierは本表とは別に検討する。
