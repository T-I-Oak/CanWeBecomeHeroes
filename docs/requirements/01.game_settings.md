# ゲーム設定資料

## ゲーム開始

- 本番ゲームの開始時には、解放済みHeroから出撃する2人を選択する。最初に選択可能なのは剣士・衛兵だけである。ゲーム中に遭遇したHeroは解放済みとなり、次回以降の開始時選択候補へ加わる。
- 出撃Heroごとに、その固有タグ傾向を持つ5部位セットを2組生成する。各セットはタグ傾向を必ず1つ含む、通常のタグ付与パターンに従う3タグ候補を先に生成する。全Itemを3タグとしてから、総タグ数に達するまでランダムにタグを削除し、残った候補枠から非復元抽選して各Itemのタグを決める。総タグ数が装備数×3を超える場合は削除せず、全Itemを3タグとする。総タグ数は5、各Itemのタグ数は最大3とする。各Itemは倉庫内の個別ランダム位置へ落下追加する。出撃Hero 2人では計4セット・20Itemとなる。

## 試験時間と貢献ポイント

- ゲーム内時間は500ticksを1時間、24時間を1日とする。初期の試験期限は7日（84,000ticks）である。
- 敵カタログの基礎貢献ポイントは、雑魚10pt・中ボス50pt・ボス250ptとする。実際に撃破時に得る貢献ポイントは、`ceil(基礎貢献ポイント × (level + 9) / 12)` とする。level3では基礎値の1倍、level9では1.5倍となる。貢献ポイントは両ゲームランモードで共通の記録・評価対象であり、複数ボスを含む高難度ステージも想定する。
- ギルドでは1回あたり最大24時間まで試験期限を延長できる。基本延長レートは `0.2H/pt × (1 + 信用タグスキルLv × 0.2)` とし、運判定成功時はさらに1.2倍する。
- 所持ptと延長レートの積が24時間以上なら、期限を24時間延長し、`ceil(24H / 延長レート)` ptを消費する。積が1時間以上24時間未満なら全ptを消費し、積と同じ時間だけ期限を延長する。積が1時間未満の場合は、全ptを消費して最低1時間を延長する。所持0ptも最低保証の対象とする。
- ギルド表示の時間軸は、現在の残り期限（紫）と貢献ポイントによる延長見込（黄）のみを連結して示す。経過時間は数値表示とし、バーには含めない。
- 時間軸の表示上限は開始時の試験期限と同じ7日とする。残り期限と延長見込の合計が現在の表示上限を超える場合だけ、その合計へ表示上限を更新する。表示上限はゲーム中に下げない。

## ステータス

- パワー・魔力・スピード・交渉力・運のMAXはデフォルト3で、訓練により最大7まで増やせる。
- タグを参照する処理では、各ステータスMAXを対応する3タグの有効タグ数上限としても使う。ステータスindexを `i`（パワー=0〜運=4）とすると、`tag[i]`・`tag[i+5]`・`tag[i+10]` の有効タグ数はそれぞれ `min(生タグ数, ステータスMAX[i])` とする。
  - パワー: 武勇・鉄・炎
  - 魔力: 魔導・布・水
  - スピード: 軽業・羽・雷
  - 交渉力: 信用・宝石・範囲
  - 運: 加護・幸運・活力
- ステータス値は、対応する2つのステータス系タグの有効タグ数の大きい方を使う。例: パワー=`min(MAX, max(武勇, 鉄))`。
- 戦闘処理・タグスキル・属性付与などで参照するタグ数は有効タグ数を使う。Itemの重量・価値と、生タグの所持履歴はこの上限で切らない。

## タグの種類

- 内部順序: 武勇、魔導、軽業、信用、加護、鉄、布、羽、宝石、幸運、炎、水、雷、範囲、活力

    - 魔導、布
    - 軽業、羽
    - 信用、宝石
    - 幸運、加護
- 属性系 5種
    - 炎、水、雷、範囲、活力

## タグの重さ、価値

- 重さ
    - 5: 鉄、宝石
    - 3: 武勇、範囲
    - 2: 魔導、信用、炎、水、雷
    - 1: 布、軽業、羽、加護、幸運、活力
- 価値
    - 5: 宝石
    - 3: 魔導、信用、加護、幸運、雷、活力、範囲
    - 2: 武勇、鉄、軽業、羽、炎、水
    - 1: 布
- 重さの計算
    - アイテムに付与されているタグの重さの合計
- 価値の計算
    - (アイテムに付与されているタグの価値の合計) × (アイテムに付与されているタグ数)
    - ただし、タグなしアイテムは価値1とする

## タグの付与パターン

- タグなし
- ステータス系 x1
- 属性系 x1
- ステータス系 x2
- ステータス系 x1 + 属性系 x1
- 属性系 x1 + 属性系 x1
- 属性系 x2
- ステータス系 x1 + 属性系 x1 + 属性系 x1
- ステータス系 x1 + 属性系 x2
- ステータス系 x2 + 属性系 x1

装備を抽選する場合は、先に主タグを決めて3タグ候補を作る。

- 主タグがステータス系: `主タグ + 同じステータス系タグ + ランダム属性タグ`
- 主タグが属性系: `主タグ + ランダムステータス系タグ + ランダム属性タグ`
- 属性系タグは重複してよい。候補は内部順序でソートし、各Itemの実際のタグ数に合わせて候補から非復元抽選する。
- 頭・胴・脚のアセット番号は、ソート後の先頭タグの内部indexを5で割った余り+1で決める。タグなしの場合は1〜5から選ぶ。

## タグの効果

- タグスキルLv
    - 同一タグ1〜2個: Lv1
    - 同一タグ3〜4個: Lv2
    - 同一タグ5〜6個: Lv3
    - 同一タグ7個: Lv4
    - 各タグスキルに記す `1 / 3 / 5 / 7` は、対応するLvを解放するための必要タグ数を表す。
    - 同一タグは最大7個として扱う。8個以上を所持していても、タグ数・タグスキルLvの計算では7個とする。

- 武勇 / valor
    - パワー値+1
    - タグスキル: 物理攻撃会心率
        - 1: 勘所
        - 3: 急所見切り
        - 5: 一撃必殺
        - 7: 英雄の一閃
- 鉄 / iron
    - パワー値+1
    - タグスキル: 物理攻撃反射
        - 1: 身構え
        - 3: 受け流し
        - 5: 不動の構え
        - 7: 聖騎士の誓約
- 魔導 / arcane
    - 魔力値+1
    - タグスキル: 魔法攻撃会心率
        - 1: おまじない
        - 3: 魔力励起
        - 5: 術式強化
        - 7: 大賢者の秘術
- 布 / cloth
    - 魔力値+1
    - タグスキル: 属性耐性
        - 1: 護りの布
        - 3: 祈りの衣
        - 5: 守護結界
        - 7: 聖者の法衣
- 軽業 / dexterity
    - スピード値+1
    - タグスキル: 盗み成功率
        - 1: 指先の悪戯
        - 3: すり抜け
        - 5: 盗人の手練れ
        - 7: 盗賊の極意
- 羽 / feather
    - スピード値+1
    - タグスキル: 回避率
        - 1: 身かわし
        - 3: 風読み
        - 5: 風走り
        - 7: 疾風の残像
- 信用 / reputation
    - 交渉力値+1
    - タグスキル: ライセンス延長量増加
        - 1: 挨拶上手
        - 3: 口利き
        - 5: 信頼の証
        - 7: 信用の極致
- 宝石 / gem
    - 交渉力値+1
    - タグスキル: 購入品強化
        - 1: 掘り出し物
        - 3: 目利き
        - 5: 秘蔵の鑑定眼
        - 7: 黄金の審美眼
- 加護 / blessing
    - 運値+1
    - タグスキル:  低スタミナ時運アップ
        - 1: 神頼み
        - 3: 守りの加護
        - 5: 奇跡の灯火
        - 7: 神恩の極み
- 幸運 / fortune
    - 運値+1
    - タグスキル: 高スタミナ時運アップ
        - 1: 小さな兆し
        - 3: 時流の巡り
        - 5: 星々の導き
        - 7: 天運の寵児
- 炎 / fire
    - 継続ダメージ(時間で減衰)
    - タグ数で継続時間増加
- 水 / water
    - 攻撃失敗率上昇(1回)
    - タグ数で失敗率増加
- 雷 / lightning

    - タグ数で伝搬量増加
- 活力 / vitality
    - 行動終了後、確率でスタミナを回復(運に依存)
    - タグ数で回復量増加
- 範囲 / area
    - 攻撃が広範囲になる(属性付与範囲も広がる)
    - タグ数で範囲・効果増加
        - 0タグ: 10
        - 1タグ: 3-5-3
        - 2タグ: 4-5-4
        - 3タグ: 1-4-6-4-1
        - 4タグ: 2-5-6-5-2
        - 5タグ: 1-3-5-7-5-3-1
        - 6タグ: 2-4-6-7-6-4-2

## ゲームの目的と仮免許

ゲームは、Heroが勇者の仮免許を取得した状態から始まる。仮免許には短い期限があり、期限内にボスを倒すことが試験であり、ゲームクリア条件である。

- 雑魚敵を倒すと、ゲーム全体で共有する貢献ポイントを得る。
- 貢献ポイントを使い、ギルドで仮免許の期限を延長できる。
- 仮免許の期限が切れる前にボスを倒せなければ、ゲームオーバーとなる。
- ボス出現条件とゲームランの進行規則は別途定義する。

## ゲームランモード

- 試験モード
  - 7日間の期限で開始し、期限内にボスを倒すことを目指すメインゲームである。
- 無限挑戦モード
  - 7日間の期限で開始し、期限が切れるまで継続して敵へ挑戦するモードである。
- アチーブメントは基本的に両モード共通とする。最高貢献ポイントのようにどちらのモードでも達成できるものを含め、最短クリアー・最長到達日数など必要なものだけモード別の条件を持たせる。
