# 情報ウィンドウ

[HeroとItemの操作要件](02.hero_item_interaction.md)に対応する詳細表示と閉じる操作を定義する。

Chip、ステータスアイコン、タグバッジ、タグアイコン、詳細内に表示する装備アイコン、エリア名・施設名の看板は、タップして対応する情報ウィンドウを開く入力とする。タグスキル名は一覧として読むための静的な表示であり、情報ウィンドウを開く入力にはしない。

情報ウィンドウの文章では、プレイヤー視点の自陣営／敵陣営をそれぞれ「味方」／「敵」と表記する。行為者から見た自陣営／敵対陣営を表す場合は、それぞれ「仲間」／「相手」と表記する。行為者がどちらの陣営にもなり得る武器・タグ・スキルの効果説明は、原則として後者を使う。

Hero・Enemy・Item・固有スキルの情報対象は、種別、定義ID、任意の実体IDで表す。実体IDを指定しない場合は種別に属する静的情報だけを表示する。実体IDを指定した場合は、同じ静的情報にその実体の現在値・装備・タグ・重量などを追加して表示する。実体IDを指定した情報ウィンドウだけは、対象実体が消滅したときに閉じる。

Enemyの階層を比較する文章では、「眷属」は対象のEnemyよりレベルが下のEnemyを表す。ボスの眷属は中ボスおよび雑魚、中ボスの眷属は雑魚とする。雑魚に眷属はいない。

内部用語では、武器を行き先アイテムを除く手の装備、装備を行き先アイテムを除くアイテム全般、アイテムを装備と行き先アイテムの総称とする。装備は装着済みかどうかを問わない。行き先アイテムは暫定的な内部呼称であり、ユーザー向けの文章では必要な場合以外に使わない。

タグスキルは、同じタグを一定数持つと自動で発動する、そのタグ固有の効果とする。タグが1・3・5・7個に達するごとに段階が上がり、効果が強化される。効果を持たないタグもある。

情報ウィンドウでは、炎・水・雷をまとめて「炎・水・雷属性」と表記する。対象へ効果を与える場合は「炎属性を付与する」のように表記し、受ける側の抑制は「炎・水・雷属性の影響を軽減する」と表記する。

情報ウィンドウの本文に、別の情報ウィンドウを持つエンティティの名称が現れる場合は、対応するアイコン付きの情報ウィンドウリンクを置くことを提案する。

情報ウィンドウの基本構成は、タイトル部とボディ部からなる。タイトル部は `アイコン | 名称`、ボディ部は対象に応じたステータス等と説明を表示する。例えば炎タグを持つ剣の情報では、タイトル部に剣Chip画像と「剣」、ボディ部に炎タグと「炎」、武器の概要説明を置く。

タグ詳細では、タイトル部にタグアイコンとタグ名を置く。ボディ部には、そのタグで増えるステータスとゲーム上の効果をアイコン付きで説明し、タグスキルを必要タグ数と名称の組で一覧表示する。武勇なら `1: 勘所`、`3: 急所見切り`、`5: 一撃必殺`、`7: 英雄の一閃` を表示する。

Hero・EnemyのChip詳細は、情報ウィンドウのタイトル部に大きなキャラクター画像と名称を置く。ボディ部は待機サブパネルの情報領域・アイテム領域を共通フォーマットとして表示し、情報領域ではパワー・魔力・スピード・交渉力・運・耐久値・総装備重量の順に7本の情報ゲージと、3行×5列のタグバッジ、アイテム領域では装備スロットを表示する。耐久値はHeroではスタミナ、EnemyではHPとする。耐久値アイコンはスタミナとHPを組み合わせ、戦闘で共通する耐久値の情報ウィンドウを開く。重量は0〜30を台形インジケーターで下から示し、実重量を下部の数値で併記する。Heroの装備は待機サブパネルと同じ十字配置とし、未装備スロットも表示する。Enemyの装備は同じアイテムスロット表現で一覧表示する。ステータス、タグ、装備はそれぞれ子の情報ウィンドウを開く。Itemの詳細では、Chip画像と名称の下に、フレーバーとプレイ上の効果をHero・Enemyと同じ緑色のプロフィール枠で表示する。付与タグ、Item自身の重量、価値は横並びのバッジとして表示し、横幅が不足する場合だけ折り返す。重量は`[おもりアイコン] N`、価値は`[価値アイコン] N`で表示し、それぞれのアイコンから対応する情報ウィンドウを開ける。付与タグからはタグ詳細を開ける。実体情報の現在スタミナ・HPは表示中も実体の現在値を反映する。

施設看板の詳細は施設の目的と、その施設内の表示が示す情報を説明する。エリア名の詳細はHome・Warehouse・Battleの目的を説明する。これらは説明用の単独ウィンドウであり、子ウィンドウを持たない。

タグスキル名は、対応する必要タグ数のタグバッジと同じ色・枠・背景の視覚トークンを使う。例えば「急所見切り」は、`[武勇アイコン 3]` のバッジと同じ段階スタイルで表示する。これにより、タグ詳細を単独で開いた場合も、タグ数とタグスキル段階の対応を一覧で確認できる。発動中であることを示す必要がある場合は、タグスキル名の段階スタイルを変更せず、説明欄の背景または先頭の状態アイコンで別途示す。タグ詳細は参照元のHero・Enemyを必須としないため、発動状態の表示は情報ウィンドウの基本要件に含めない。

- 情報ウィンドウのタイトル部に閉じるボタンを置く。閉じる操作は、そのウィンドウと子孫を閉じる。ピン止めしたウィンドウも閉じるボタンで閉じられる。
- 情報ウィンドウ内のアイコンをタップした場合は、そのウィンドウの上に子の情報ウィンドウを重ねて開く。親ウィンドウは残す。親が同時に保持できるピン止めしていない子ウィンドウは1つだけとし、親内の別アイコンから子を開く時は、ピン止めしていない既存の子とその子孫を閉じて新しい子へ置き換える。ピン止めしたウィンドウは残す。
- タップ位置を含む最も深い情報ウィンドウと、その祖先は残す。それ以外のピン止めしていない子孫・枝は閉じる。したがって、AからBを開いた状態では、A内かつB外をタップするとBだけが閉じ、B内をタップするとA・Bが残り、A・Bの外部をタップすると両方閉じる。B内のアイコンからCを開く場合はA・Bを残したままCを重ねる。
- 時間設定では、情報ウィンドウを開いた時にゲーム時間を停止するかを切り替える。この設定が有効で、ピン止めしていない情報ウィンドウが1つ以上開いている間だけ、独立した停止理由として `GameClock` へ通知する。手動停止・試験課題選択・自動停止とは独立して扱う。
- ピン止めしたウィンドウは外側をタップしても残り、ゲーム時間を停止させない。
