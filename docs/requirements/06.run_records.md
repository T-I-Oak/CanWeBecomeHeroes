# ランの集計と記録

## 1. 集計範囲

ゲーム中の事実を、今回のラン用と累積用に収集する。一般集計はモードを分けない。試験・チャレンジの開始回数と試験の合格・不合格回数はモードと初期Heroの組合せごとに保持する。組合せは順不同の全28組である。

一般集計は以下を扱う。

- 課題種類・構成indexごとの挑戦回数、クリアー回数、最高クリアーレベル、その最高レベルを最後にクリアーした日時。低いレベルのクリアーでは最高レベルの日時を更新しない。旧記録の不明な日時は生成しない。
- 敵種ごとの討伐回数と、獲得貢献ptの合計。ギルドで消費しても獲得合計は減らない。
- ギルドで実際に消費した貢献ポイントの合計（今回ラン・累積に収集）。
- 施設ごとの出発回数とHero別の出発回数。目的地への出発確定時に数える。倉庫は対象外。
- Hero・武器種類ごとの装備回数。試験場への出発確定時だけ、装備武器1個につき1回を数える。他施設への出発では数えない。
- Hero・タグごとの最高タグ数。Hero本体と装備のタグを合わせ、能力上限を適用しない。
- タグスキルがある10種類は、同じ時点の装備込みタグ数・対応ステータスMAX・7の最小値を有効タグ数として、Hero・タグごとの最高値も保持する。アチーブメントとスキル由来の二つ名にはこの値を使う。初期生成・加入・装備変更・解除・訓練によるMAX更新時に記録する。別時点の最高保持数とMAXを組み合わせない。
- Heroごとのショップで宝石スキルによって購入品へ実際に追加されたタグ数、ギルドで成立した延長時間、訓練で幸運によってスタミナ消費が減った成功回数。宝石追加タグ数は配送処理時に集計し、倉庫満杯で購入品を入手できない場合も能力が発揮された追加分として数える。生成時のタグ数上限などで実際にタグが増えなかった場合は数えない。

ラン用だけに、特定できた討伐者Heroごとの敵種別討伐回数と、その敵を倒した課題レベルの最高値を保持する。討伐者は最後のダメージを与えたHeroとする。炎の付与元Heroが分かる場合も含み、不明な攻撃者や敵同士の攻撃を推測しない。

Itemの全件履歴、戦闘ログの全件履歴、通算の討伐者別履歴は保存しない。

## 2. 保存と終了記録

メモリ上の集計は随時更新する。課題決定とゲーム終了の集計を反映した後に、共通DataManagerのゲーム名前空間へ保存する。

途中でページを閉じた場合、最後に保存が成功した時点までの累積集計が残る。終了履歴は作らず、途中のゲーム状態や再開データも保存しない。

試験合格・期限切れの終了記録には、ランID、開始・終了日時、モード、結果、到達ステージ、開始Hero、順序を保持した終了メンバー、経過ticks、残り期限、クリアー課題数、獲得貢献pt、敵討伐数、ラン内集計、アチーブメントの判定結果を保持する。

終了履歴は最新50件を保持する。終了済み試験数、合格・不合格回数、終了ランの獲得ptの合計と最高値、記録された初回・直近合格日時と合格回数は履歴上限で減らない。一般の累積集計には、途中ランの保存分も含まれるため、終了ランだけの統計と区別する。

終了通知と保存再試行では二重集計しない。保存失敗時もメモリ上の未保存データを保持し、保存処理の再呼び出しで二重集計しない。画面下部に未保存の通知と保存再試行ボタンを表示し、成功するまでタイトルへ戻っても維持する。

現在の形式の解放状況、クリアーフラグ、設定、言語、チュートリアルを維持する。新規の記録は独立した未達成状態から作成し、旧クリアーフラグの引継ぎや、旧データからの日時・回数・成績の生成は行わない。

## 3. ランキング

ランキングはアチーブメントから独立して、ゲーム終了時に終了結果を登録する。

| モード | 順位基準 |
| --- | --- |
| 試験 | 残り期限、討伐数、獲得貢献pt |
| 実力判定試験 | クリアー課題数、経過時間、討伐数、獲得貢献pt |

各値は大きい方が上位。同順位は終了時刻が新しい方を上位とする。試験不合格の残り期限は0とし、不合格同士の残り期限の順位はクリアー課題数を比較する。

基準ごとに上位N件、Nは定数で10件とする。全基準の上位N件の和集合を保持し、どの基準にも入らないランキングデータは破棄する。独立した直近50件の終了履歴はこの削除の影響を受けない。

実力判定試験のランキングは勇者認定試験の合格後に表示する。クリアー課題数と終了通知の到達課題番号を区別し、第8課題挑戦中に終了した場合はクリアー課題数7、到達課題番号8とする。

## 4. 判定と表示

基礎情報の収集・保存、アチーブメント定義・評価・差分判定、ランキングの収集・順位付け・保持・保存とする。アチーブメントの最新仕様は[アチーブメント仕様](../specifications/14.achievements.md)を参照する。ゲーム終了情報を値として渡し、グレード更新をコールバックで通知する。

トースト・終了画面・共通CSSとDOM生成は実装済み。レコード画面は勇者認定試験・実力判定試験のランキング、アチーブメント、課題記録を表示する。アチーブメントは表示時の評価がD-以上、または結果画面の表示項目として確定済みの項目だけを定義順に表示する。結果画面の表示項目は評価Eも含めIDごとの既知フラグを保存し、裏面の閲覧を条件にしない。D-以上への到達ではフラグを更新しない。表示対象がない場合は試験を受けるよう案内を日英で表示する。保存形式の補完・既知フラグの推定・自動移行・不整合時の黙示的な初期化は行わない。列・選定・進捗・画像・日時・操作の詳細は[レコード仕様](../specifications/16.run_records.md)を正本とする。

比率表示、終了履歴・ラン詳細の閲覧、記録削除・出力・共有は対象外。閲覧・切替・言語変更では記録を更新せず、日本語・英語、スマートフォン縦横の内部スクロールとタイトル復帰に対応する。保存失敗の通知・再試行は画面共通で扱う。

正式な合格・不合格通知と、合格時の二つ名選定・表示は実装済み。詳細は[試験終了画面仕様](../specifications/17.trial_result_screen.md)を正本とする。

成績表は更新ありを優先し、更新・非更新のそれぞれで累積G値の増加量（deltaG）が大きい順、終了後の累積G値（G）が0以外で小さい順、G値0、定義順の順に選定する。後ろのキーは前のキーが同じ場合だけ使用し、グレードの上昇段階数は比較しない。同じIDを重複採用せず上位10件を選定した後、全件を定義順で表示する。入力データを変更しない。
