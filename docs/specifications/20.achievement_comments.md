# アチーブメントの評価項目名と所見

判定・集計・表示モードは[アチーブメント仕様](14.achievements.md)を参照する。本書は評価項目名と所見の正本とし、言語別の表示リソースは`AchievementDefinitions`で生成する。

タグの所見は、装備込み所持数を記録時点の対応ステータスMAXと7で制限した最高有効タグ数から選ぶ。1〜2・3〜4・5〜6・7個の区分が、実際に使用できたスキルLv1〜4に対応する。
