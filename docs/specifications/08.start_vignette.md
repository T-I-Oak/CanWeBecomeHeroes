# 開始劇

開始劇の内容である。寸劇のインタフェースは[寸劇](07.vignette.md)に従う。プレイヤーが受け取るシナリオの `heroId` は、すでに英雄の id である。パーティーのリストはシナリオには無く、シナリオジェネレーターが受け取る。

開始劇のジェネレーターは、パーティー選択の直後、試験の開始前に、確定したリストを選択順のまま受け取る。アヴェリーとブライアー、ケイシーとダーシー、エリスとフィンリー、ガーネットとハーパーのときは、選択順にかかわらず、後述のその組の特殊シナリオを作る。それ以外は基本シナリオを作る。基本シナリオでは、先頭の英雄を `lead` の `heroId`、その次の英雄を `partner` の `heroId` とする。特殊シナリオの `instances` の `id` は、その英雄の `id` である。`instances` の先頭が最前面である。プレイヤーはそのシナリオを再生する。基本シナリオとアヴェリー・ブライアーの入場、停止、退場、ピンチの数値は、同じ定義から置く。ケイシーとダーシー、エリスとフィンリー、ガーネットとハーパーの背景、入場、停止、退場は、それぞれの節に置く。

基本シナリオのコマンドは次である。歩行は 90px/秒である。距離は、その速さから秒へ換算している。`line` の `seconds` は実装の一つの定数で、値は 3 である。最初に話す側の `direction` は `up`、後から話す側は `down` である。`line` の `text` は、言語リソース `vignette.opening.lead.<heroId>` と `vignette.opening.partner.<heroId>` を、その役の英雄の id で引いた文である。リソースにその文が無いときは、シナリオを作らない。`line` の `borderColor`、`backgroundColor`、`backgroundOpacity`、`color`、`outlineColor`、`outlineWidth` は書かず、インタフェースの既定値を使う。`fillColor` は、準備エリアで待っている英雄チップの色 `#bfdbfe` である。

`instances` は `lead`、`partner` の順である。`lead` が最前面である。

| 順 | `type` | プロパティ |
| --- | --- | --- |
| 1 | `background` | `asset` は `assets/vignette/village.png`、`scrollX` は -48 |
| 2 | `pinchOut` | `seconds` は 0.7、`wait` は -1 |
| 3 | `position` | `instanceId` は `lead`、`x` は -80、`y` は 248、`seconds` は 0、`wait` は -1 |
| 4 | `facing` | `instanceId` は `lead`、`direction` は `right`、`stepDistance` は 24、`forwardSeconds` は 0.14、`backSeconds` は 0.5、`phase` は 0、`chipRadius` は 56、`fillColor` は `#bfdbfe` |
| 5 | `position` | `instanceId` は `lead`、`x` は 200、`y` は 248、`seconds` は 280/90、`wait` は -1 |
| 6 | `line` | `instanceId` は `lead`、`text` は `vignette.opening.lead.<lead の heroId>`、`width` は 528、`seconds` は 3、`direction` は `up`、`wait` は -1 |
| 7 | `position` | `instanceId` は `partner`、`x` は -80、`y` は 248、`seconds` は 0、`wait` は -1 |
| 8 | `facing` | `instanceId` は `partner`、`direction` は `right`、`stepDistance` は 24、`forwardSeconds` は 0.14、`backSeconds` は 0.5、`phase` は 0.25、`chipRadius` は 56、`fillColor` は `#bfdbfe` |
| 9 | `position` | `instanceId` は `partner`、`x` は 70、`y` は 248、`seconds` は 150/90、`wait` は -1 |
| 10 | `line` | `instanceId` は `partner`、`text` は `vignette.opening.partner.<partner の heroId>`、`width` は 528、`seconds` は 3、`direction` は `down`、`wait` は -1 |
| 11 | `position` | `instanceId` は `lead`、`x` は 416、`y` は 248、`seconds` は 2.4、`wait` は 0 |

退場は、停止位置から 90px/秒で 2.4 秒進む。先導は 200 から 416、相方は 70 から 286 である。どちらも、この時点では画面の右の外までは出ていない。12 は 11 の完了を待たずに始まり、13 は 12 の開始から 1.5 秒後に始まる。13 は枠が閉じるまで次へ進まない。11 と 12 の歩行完了は待たない。

足踏みが後ろへ戻る速さは 24/0.5 = 48 で、背景が左へ動く速さ `-scrollX` と同じである。背景ファイルは `public/assets/vignette/village.png` で、道は y=248 に描く。

## アヴェリーとブライアー

この組み合わせの会話は、基本シナリオとは別のシナリオである。選択順にはよらない。シナリオは一つである。`instances` の `id` は `Avery`、`Briar` の順で、`Avery` が最前面である。登場順も立ち位置もこれで固定する。`Avery` の停止 x は 200、`Briar` の停止 x は 70 である。コマンドの `instanceId` は、その `id` である。

背景、ピンチ、足踏み、入場の数値は基本シナリオと同じである。最初の部分の順も基本シナリオと同じである。アヴェリーが入場して 1 を言い、ブライアーが入場して 2 を言う。

会話は言語リソース `vignette.opening.scripts.AveryBriar` の配列である。各要素は `heroId` と `text` を持つ。`text` は `lang-store` である。配列が無い、または文が空のときは、シナリオを作らない。配列の順は次である。

| 順 | `heroId` | 動き |
| --- | --- | --- |
| 1 | Avery | 停止したまま |
| 2 | Briar | 停止したまま |
| 3 | Avery | 停止したまま。「案内によると……」 |
| 4 | Avery | 停止したまま。「7日間で7回も戦わないといけないの！？」 |
| 5 | Avery | 「時間がない、急がないと！！」と同時に右へ歩き出す。`wait` は 0。歩行の完了は待たない。次のセリフと同時に出たまま残る |
| 6 | Briar | 5 と同時に始まる。アヴェリーは歩き続ける。ブライアーは停止したまま |
| 7 | Briar | セリフと同時に右へ歩き出す。移動と足踏みの前後は、ほかの 2 倍の速さである。歩行の完了は待たない |

各セリフの `width` は 528、`seconds` は 3 である。`wait` は 5 だけ 0 で、ほかは -1 である。5 と 6 は 3 秒のあいだ同時に出る。5 の秒数が終わると 5 だけ消える。高さは本文の折り返し行数から決まる。最初の話者であるアヴェリーの `direction` は `up`、後の話者であるブライアーの `direction` は `down` である。歩き出す `position` は、そのセリフの直前に置く。`y` は 248、`wait` は 0 である。5 の速さは 90px/秒、7 の速さは 180px/秒である。7 の開始時に、その英雄の `facing` を置き直す。歩幅 24 はそのまま、`forwardSeconds` は 0.07、`backSeconds` は 0.25 である。歩行の秒数は、歩き出してから `pinchIn` が終わるまでである。5 は自分の表示を待たないので、6 と 7 の 3 秒に `pinchIn` の 0.7 秒を足した 6.7 秒である。7 は自分の 3 秒に 0.7 秒を足した 3.7 秒である。目的の `x` は、停止位置にその速さと秒数の距離を足した値である。枠が閉じるまで歩き続ける。

7 のセリフが終わってから `pinchIn` を始める。`seconds` は 0.7、`wait` は -1 である。

## ケイシーとダーシー

この組み合わせの会話は、基本シナリオとは別のシナリオである。選択順にはよらない。シナリオは一つである。`instances` の `id` は `Casey`、`Darcy` の順で、`Casey` が最前面である。登場順も立ち位置もこれで固定する。コマンドの `instanceId` は、その `id` である。

背景は `assets/vignette/village.png` の静止である。`scrollX` は 0 である。`pinchOut` と `pinchIn` の `seconds` は 0.7、`wait` は -1 である。足の y は 248 である。歩いているあいだの速さは 90px/秒である。歩いているあいだの `facing` は、歩幅 24、`forwardSeconds` は 0.14、`backSeconds` は 0.5、`chipRadius` は 56、`fillColor` は `#bfdbfe` である。ケイシーの `phase` は 0、ダーシーの `phase` は 0.25 である。停止したときは、同じ向きの `facing` を `stepDistance` 0 で置き直し、足踏みを止める。向きは変えない。

## エリスとフィンリー

この組み合わせの会話は、基本シナリオとは別のシナリオである。選択順にはよらない。シナリオは一つである。`instances` の `id` は `Ellis`、`Finley` の順で、`Ellis` が最前面である。コマンドの `instanceId` は、その `id` である。

背景は `assets/vignette/village.png` である。`scrollX` は -90 で、歩行と同じ 90px/秒で絵を左へ動かす。`pinchOut` と `pinchIn` の `seconds` は 0.7、`wait` は -1 である。足の y は 248 である。並んだときのフィンリーの x は 70、エリスの x は 224 である。フィンリーが左、エリスが右である。エリスは左を向くので、足踏みは停止位置から左へ 24px 動く。描画範囲は 200 から 224 で、通常版の右向きの先導と同じ範囲になる。

背景は `assets/vignette/village.png` である。`scrollX` は -90 で、歩行と同じ 90px/秒で絵を左へ動かす。`pinchOut` と `pinchIn` の `seconds` は 0.7、`wait` は -1 である。足の y は 248 である。向きは右のままである。足踏みは基本シナリオと同じで、歩幅 24、`forwardSeconds` は 0.14、`backSeconds` は 0.5、`chipRadius` は 56、`fillColor` は `#bfdbfe` である。ガーネットの `phase` は 0、ハーパーの `phase` は 0.25 である。1キャラ分は、基本シナリオの停止間隔 200−70＝130px である。2キャラ分は 260px である。
