# アイコン視覚システム

## 1. 目的

タグ、ステータス、属性エフェクトを、同じ意味の色・図柄・動きで関連付ける。
ゲーム画面ではタグアイコンを最終的に 64px で表示するため、縮小時の判読性を最優先する。

## 2. タグアイコンの構成

タグアイコンは、共通外枠、分類色ベース、タグ固有図柄を別レイヤーとして構成する。

- 共通外枠: `public/assets/tags/frame.png`
- 分類色ベース: 描画時に6分類の色で円盤を描く
- タグ固有図柄: 各タグの透過図柄レイヤー

共通外枠はすべてのタグで同一のものを使用する。タグ固有図柄は円盤・枠を含めず、外枠の中央の開口部に収める。描画順は「分類色ベース → タグ固有図柄 → 共通外枠」とする。これにより、生成時の個体差で枠の太さや装飾位置が揺れることを防ぐ。

## 3. 64pxでの設計制約

- 最終表示寸法は 64px 四方とする。
- タグ図柄のソースは 1024px 四方・透明背景とする。図柄は中央の直径1024pxの円内へ収め、円盤・枠・背景を含めない。
- 図柄はソース画像全体を大きく使ってよい。フレーム内に収めるための余白は、アセットごとではなく描画側の共通倍率で確保する。
- 外枠は図柄より前面に描画する。
- 図柄は、細い文字・細密な模様・小さな副記号に依存して意味を伝えてはならない。
- タグ数・タグスキルレベルは図柄へ焼き込まず、UIのバッジ・枠・背景で別途示す。
- 既存画像を移行する間は、円盤を含む旧画像を使用してもよい。透過図柄へ置換されたタグから分類色ベースが視認できる。

## 4. フレームの分類色

外側・内側の銀縁と形状は共通とし、エナメルリングだけをタグ分類ごとに色分けする。色の調整が必要になった場合は、共通フレームを元にエナメル部だけを再配色する。

| 分類 | 対象タグ | エナメル色 |
| --- | --- | --- |
| パワー | 武勇・鉄 | 茶 |
| 魔力 | 魔導・布 | 紫 |
| スピード | 軽業・羽 | シアン |
| 交渉力 | 信用・宝石 | 明るい金 |
| 運 | 加護・幸運 | 黄緑 |
| 属性 | 炎・水・雷・活力・範囲 | 真珠色の淡い青灰 |

パワーには炎との誤認を避けるため赤・橙を使用しない。属性フレームは中央の属性図柄を際立たせるため、属性ごとの枠色には分けない。

## 5. 属性との対応

炎・水・雷のタグ図柄と、戦闘中の属性オーバーレイは、同一属性と認識できる色・図形モチーフ・アニメーションを共有する。

- タグ図柄: 常時見える識別用の簡潔な図柄
- 属性オーバーレイ: キャラクターを囲み、属性付与値を大きさ・動きで示す演出

水は深い青、水面、霧、波紋を共通モチーフとする。属性オーバーレイは中央を大きく空け、キャラクターの視認性を妨げない。

## 6. ステータス表示との対応

ステータス表示は、アイコンと色の両方で種別を示す。7セグメントゲージでは、点灯セグメントの色とは別に、ゲージの土台・外枠へステータス固有色を使用する。

パワーの色は炎との誤認を避けるため、炎系の赤・橙を使用しない。タグ図柄・ステータスアイコンの最終的な色と形状は、相互の見分けやすさを確認して決定する。
