# 戦闘シミュレーション

## 目的

実装済みの戦闘処理を、描画・チップ物理・UIなしで複数試行し、タグ構成・装備・ステータスによる実測値を比較する。シミュレーターは戦闘式を複製せず、実ゲームと同じ `BattleSystem` を呼び出す。そのため、戦闘処理の追加・変更はシミュレーション結果にも反映される。

## 実行

```powershell
npm run simulate:battle -- <conditions.json>
```

標準出力へ整形済みJSONを出力する。

最小の比較例は `examples/simulations/valor-x3-vs-iron-x3.json` であり、次のように実行できる。

```powershell
npm run simulate:battle -- examples/simulations/valor-x3-vs-iron-x3.json
```

```json
{
  "ticks": 10000,
  "trials": 10000,
  "seed": 1,
  "left": [
    { "label": "武勇x3", "tags": ["valor", "valor", "valor"], "weapons": ["sword"] }
  ],
  "right": [
    { "label": "鉄x3", "tags": ["iron", "iron", "iron"], "weapons": ["sword"], "maximumHp": 3 }
  ]
}
```

- `left` はHero陣営、`right` はEnemy陣営であり、各配列は複数キャラクターを指定できる。
- `tags` はキャラクター自身が持つタグ。`Aタグx3` は `["A", "A", "A"]` と指定する。
- `maximums` はHeroの各ステータスMAXを上書きする。未指定時は全て3。
- Heroの初期スタミナは `stamina`、Enemyの初期HPは `maximumHp` で指定する。未指定時はいずれも3。
- `weapons` は武器種配列。未指定のHeroは素手2回、Enemyは素手1回で攻撃する。
- `seed` を固定すれば同じ入力から同じ結果を再現できる。

## 出力

出力は勝敗数・勝率、平均戦闘tick、平均与ダメージを返す。ダメージは陣営別のほか、武器種、炎継続ダメージ、鉄反射ダメージの発生源別に集計する。属性付与は最新の付与値を採用する実装に合わせ、炎の継続ダメージはその値を付与した攻撃者へ帰属させる。

結果は実装済みの戦闘ルールだけを反映する。未実装のタグスキル・固有スキル・回復処理などは含めない。
