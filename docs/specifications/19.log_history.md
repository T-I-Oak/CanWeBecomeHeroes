# ログ履歴ウィンドウ

## 記録と寿命

現在のランのGameLogを唯一の記録元とし、ラン開始からの全件を発生順で閲覧できる。notify: falseも対象とする。過去ランの保存・再読込は行わない。ラン終了時に情報ウィンドウを閉じ、履歴部品・購読を破棄する。

アチーブメントはStatisticsCollectorが渡す通知の各項目を、トーストへのenqueueと同じ接続点で1件ずつ記録する。通知IDと到達判定をlogAchievementの構造化パラメータへ保持し、notify: falseとする。表示時はAchievementDefinitionsから現在言語の項目名・到達判定を解決する。ラン開始・初期Hero接続時の通知も対象とし、保存済み達成の初期評価は記録しない。トーストの再表示・破棄・言語変更からは記録しない。

## 情報ウィンドウとの統合

HUDの文書アイコン付きログ履歴ボタンから、type: log-historyの情報ウィンドウを開く。同じ履歴は重複作成しない。移動、ピン止め、拡縮、親子関係、閉じる操作、情報ウィンドウ表示時の停止設定はInformationWindowManager・Tree・Layerの標準処理を利用する。履歴専用の停止理由とトースト停止処理は設けない。劇の表示中は、履歴を含む情報ウィンドウを劇より背面に置く。

createLogMessagePartsとLogMessageViewをフロート表示と共用する。Hero・Enemy・Item・Exスキルはdefinition、タグ・ステータス・用語・施設・エリアは対応する静的参照を子ウィンドウとして開く。過去の個体状態を再現しない。

## 絞り込み

2つの表示スイッチを設け、初期値は両方ONとする。変更は過去の記録にも適用し、GameLog自体を削除・変更しない。表示文面は判定に使わない。

| スイッチ | OFF時の非表示条件 |
| --- | --- |
| 通常ダメージ・ミスを表示 | localized.keyがlogDamageまたはlogMiss |
| Exスキル関連を表示 | channelがex-skill |

Exスキルの専用ログ19種はex-skillへ分類する。スキルの影響を受けた通常攻撃のダメージ・会心・撃破はbattleのままとする。FlowLogではbattleとex-skillを同じ戦闘用の表示位置として扱う。

## スクロールと表示負荷

初回表示は最新位置とし、末尾閲覧中は新着へ追従する。過去閲覧中は新着で位置を動かさない。「最新へ」で追従へ戻る。表示スイッチ変更時は末尾へ移る。スイッチ値は共通DataManagerのゲーム固有領域can-we-become-heroes内のlogHistoryFiltersへ変更時に保存し、新しいランや再読み込みでも復元する。初期値は共通DataManagerのgetSavedDataへ渡すinitで両方ONと定義し、保存はsetSavedDataを使う。機能側で未保存・型の判定や欠損項目の補完を行わない。独自のデータ変換処理は設けない。ログ本文自体は永続化しない。

VirtualLogListは行高の実測値と未表示行の推定値から累積高さを算出し、表示範囲と前後6行を基本に描画する。長文は折り返す。画面幅・言語変更時は高さを再計測する。InformationWindowLayerの再描画では本文DOMを再利用し、ピン止め・子情報の開閉・拡縮でスクロール位置を保持する。

既存PaperScrollの内部スクロールを使い、ページ全体はスクロールさせない。本文は18px、表示スイッチと最新へ操作は16pxを基準とする。履歴にも標準の情報ウィンドウscaleを適用する。測定・scrollTopは拡縮前のレイアウト座標で扱い、拡縮後の配置・リサイズは既存Positioner・ResizeControllerへ委ねる。

## 設定の入口

設定はタイトル・ゲーム共通の右上ギアボタンから開く。HUDとタイトルメニューに設定コマンドは置かない。タイトル時は既存menu、ゲーム時は既存hudの設定表示を使用する。ギアには日英の読み上げ名・ツールチップ、ホバー回転、押下反応を設ける。フォーカスは既存の共通処理で残さない。画面端はsafe areaを考慮し、動き低減設定では回転を行わない。
