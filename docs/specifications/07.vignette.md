# 寸劇

寸劇は、画面に固定したモーダルで、シナリオオブジェクトを先頭から実行して描く。

## 1. 画面

基準座標は幅 560、高さ 400 である。原点は左上、y は下向きである。この矩形が表示領域であり、背景を描く範囲である。枠はこの矩形の外にあり、太さは 560×400 に含めない。

枠は太さ 4px、色 `#9b7142`、角丸 14px である。

表示は `view` が行う。`view` は、基準座標の絵をビューポートのどこへ、どの濃さで、どの範囲を切って置くかを持つ。ビューポートに対する拡大率を決め、ウィンドウのリサイズに追従するのも `view` である。シナリオのコマンドは `scale` を持たない。

`view` の状態は次である。

| プロパティ | 意味 |
| --- | --- |
| `clip` | 基準座標の矩形。`x`、`y`、`width`、`height`。560×400 のうち見せる範囲である。枠はこの矩形の画面上の外辺に付ける |
| `offsetX`、`offsetY` | 収め位置からのずれ。単位は基準座標の px。0 が収め位置である |
| `opacity` | 濃さ。0 以上 1 以下である。0 は透明、1 は不透明である。絵と枠の両方に掛ける |
| `scale` | 基準座標から画面座標への単一倍率。`view` がビューポートから計算する |

ビューポートの各辺から余白 `padding = clamp(10px, 3vmin, 28px)` を取る。枠の太さを `border = 4px` として、次の倍率を使う。

```text
availableWidth = viewportWidth - padding * 2 - border * 2
availableHeight = viewportHeight - padding * 2 - border * 2
scale = min(availableWidth / 560, availableHeight / 400)
```

収め位置は、560×400 の全体を、余白と枠の内側の中央に置く位置である。基準座標の点 (`rx`, `ry`) の画面座標は次である。

```text
restX = padding + border + (availableWidth - 560 * scale) / 2
restY = padding + border + (availableHeight - 400 * scale) / 2
screenX = restX + (rx + offsetX) * scale
screenY = restY + (ry + offsetY) * scale
```

背景、チップ、セリフ、文字、縁取りは、この `scale` で描く。画面の縦横比が変わっても、基準座標上の比率は変えない。リサイズしたときは `scale` と収め位置だけを計算し直す。`clip`、`offsetX`、`offsetY`、`opacity` は基準座標のまま残す。

再生開始時の `view` は、`clip` が `{ x: 280, y: 200, width: 0, height: 0 }`、`offsetX` と `offsetY` が 0、`opacity` が 1 である。見える範囲はない。

枠のアクションは、`view` の `clip`、`offsetX`、`offsetY`、`opacity` を時間で変えるコマンドである。チャンネルは別である。`clip` を変えるコマンドは、ずれや濃さを変えない。ずれを変えるコマンドは、`clip` や濃さを変えない。この文書が定義する枠のコマンドは、`clip` を変える `pinchOut` と `pinchIn` だけである。上から滑り込ませる、滑り出させる、揺らす、といったアクションは、同じ `view` のずれまたは濃さを変えるコマンドとして足せる。それらのコマンドはこの文書にはまだ無い。

### 1.1 セリフ

`line` の任意の `action` は発言開始時の話者の動きである。`{ type: 'hop', height: 7, seconds: 0.32 }` は指定時間で一度跳ねる。上下の表示オフセットは `-height * sin(π * elapsed / seconds)`、終了後は0で、位置コマンドの座標は変えない。吹き出しは同じオフセットに追従する。省略した台詞に動きは付けない。

セリフは、表示中のものをすべて描く。各吹き出しは、その `line` の `seconds` が終わるまで残る。あとから始まった `line` は、すでに出ている吹き出しを消さない。`instanceId` のチップから、`direction` の側に吹き出しを出す。`direction` を省略したときは下である。下はチップの下、上はチップの上、左はチップの左、右はチップの右である。位置は、描画の時点のチップの中心と半径から決める。歩いているあいだも、チップに付いて動く。位置も `facing` も無いインスタンスの吹き出しは描かない。

吹き出しの本体は、幅が `width` である。高さは、`text` を折り返した行から決まる。上の内側余白 16px、行の開始位置の間隔 40px を行数から 1 を引いた回数、最後の行で字形が届く高さ、下の内側余白 16px を足す。行数の指定は無い。最後の行の下には、行間隔の余りを足さない。枠の内側の余白に入りきらない行は、そこまでを高さの上限にする。本体とチップのあいだに、長さ 14px、底辺 22px の三角を付ける。三角の底は、本体のチップに向いた辺に付く。頂点はその辺からチップの側へ 14px 出る。頂点の、辺に沿った位置はチップの中心に合わせる。頂点が角に乗るときは、角の丸み 12px と底辺が辺に収まる位置まで、辺に沿ってずらす。

枠の内側には 16px の余白を取る。吹き出しの本体と三角は、基準座標の舞台からこの余白を除いた範囲に収める。指定の側に置くと余白を超えるときは、超えない位置まで平行にずらす。下と上では、先にチップの中心と本体の中心を水平にそろえる。左と右では、先にチップの中心と本体の中心を垂直にそろえる。

書体はアプリケーションの本文書体である。文字サイズは基準座標で 28px、次の行の開始位置は 40px 下である。本文は、本体の上から 16px、左から 8px の位置から描く。吹き出しの下端は、最後の行の文字の下端から 16px 下である。折り返しの幅は、`width` から左右の内側余白 8px を引いた値である。次の文字を足すと折り返しの幅を超えるとき、その行に空白があれば、最後の空白の直後で折り返す。次の行はその次の文字から始まる。空白が無いときは、その文字の前で折り返す。その結果、次の行が行頭禁則文字で始まるとき、または折り返し位置の直前が行末禁則文字のときは、そうでなくなるまで 1 文字ずつ前へ戻す。行頭禁則文字は、JIS X 4051 の終わり括弧類、句点類、読点類、中点類、区切り約物、繰返し記号、長音記号、小書きの仮名である。「！？」や「……」のように禁則文字が続くときは、直前の文字と一緒に次の行へ移る。行末禁則文字は、始め括弧類である。戻すと行が空になるときは、そこでは戻さない。本文は `text` だけである。吹き出しの地は `backgroundColor` で、濃さは `backgroundOpacity` である。地の既定色は文字の縁と同じ `#1c140c` である。枠は `borderColor` で、太さは 2px である。枠と三角の縁は地の濃さに含めず、不透明に描く。文字は `color` で塗り、縁は `outlineColor`、太さは `outlineWidth` である。文字の縁も地の濃さに含めない。

### 1.2 チップ

チップは円である。半径は、そのインスタンスの `facing` の `chipRadius` である。円の下端の中点が足の位置である。中心 x は足の x に足踏みのオフセットを加えた値、中心 y は足の y から `chipRadius` を引いた値である。地の色は `fillColor` である。円の中の絵は、インスタンスが対応するキャラクター、アイテム、エネミーのチップ絵である。`direction` が `right` のときは画像の正方向、`left` のときは左右反転である。

オフセットは前方向への水平移動だけである。`right` なら x を増やし、`left` なら x を減らす。上下には動かさない。

体が完全に左の外へ出る足の x は、`-chipRadius` 以下である。完全に右の外へ出る足の x は、`560 + chipRadius` 以上である。二つの円が横に接するとき、足の x の差は半径の和である。

### 1.3 背景画像

一度に見える範囲は 560×400 である。横へ流す背景は、高さを 400 に合わせ、幅を 560 以上にする。左端と右端は同じ景色としてつながり、横へ繰り返せる。推奨サイズは 1120×400 である。ファイルもこのサイズで描く。幅をさらに長くする場合も、高さは 400 のままにする。

描画高さは 400、描画幅は画像の縦横比から求める。その `background` を実行してからの経過秒を `elapsed`、描画幅を `width` として、画像左端の変位は `offsetX + scrollX * elapsed` である。`offsetX` は開始時の表示位置で、既定値は0。正の `scrollX` は絵を右へ動かし、負の `scrollX` は絵を左へ動かす。`width` で繰り返すため、変位に `width` の整数倍を足して 0 以上 `width` 未満にした値を `r` とする。画像は x = `r - width` と x = `r` に描き、560×400 で切る。

セリフの下に見える絵は背景の一部である。道を描く場合、その高さは、その画像を使う劇の足の y に合わせる。

絵のタッチは `public/assets/vignette/village.png` を基準にする。別の寸劇の背景も、このタッチから変えない。

- 視点は、舞台の背景を正面から見た横長の景色とする。上から見た地面のタイルにはしない。
- 画材は、輪郭線のない水彩に近い絵の具とする。塗りはマットで、筆のタッチがわずかに残る。写真のような質感、アニメのセル塗り、強いインクの輪郭、発光、暗い劇的な陰影は使わない。
- 光は柔らかい昼とする。空は薄い青に白い雲を置き、遠景は青く霞ませる。コントラストは抑え、影は短く淡くする。
- 色はくすんだ自然色に限る。緑、土の茶、石の灰、屋根の赤茶、空の薄い青を基調とし、原色や蛍光色は使わない。
- 家、木、道などの形は、輪郭が読める程度に単純化する。葉や草を 1 枚ずつ描き込まない。セリフが重なる手前の地面は、奥の景色より模様を少なくする。
- 人物、動物、文字、記号、枠、画面の部品は描かない。

### 1.4 スキップ

モーダルの右下に、再生の絵とは別のボタンを固定する。表示文は `>>Skip` である。`view` の `clip`、`offsetX`、`offsetY`、`opacity`、枠の位置と大きさには従わない。再生を開始したときから、再生が終わるまで、押せる。押すと、残りのコマンドを待たずに再生を終える。終了時の時計の解除は、4 の通常終了と同じである。

## 2. シナリオオブジェクト

シナリオは次のオブジェクトである。モーダルの大きさ、セリフ領域の大きさ、文字、枠の見た目、スキップボタンは持たない。

```js
{
  instances: [ /* 2.1 */ ],
  commands: [ /* 3 */ ],
}
```

`commands` は添字 0 から順に実行する。コマンドは `type` を持つ。プロパティは省略できる。省略した値は、3 の表の既定値である。直前のコマンドに書いた値は引き継がない。無限継続系は `seconds` と `wait` を持たない。

### 不正なシナリオ

次は不正なシナリオである。

- `instances` が配列でない、または `commands` が配列でない。
- `id` が空である、または同じ `id` が二度出る。
- `kind` と参照プロパティの組が 2.1 のどれでもない。
- `heroId` が英雄の id でない。`enemyId` がエネミーカタログの id でない。`itemId` がアイテムカタログの id でない。
- `type` が 3 のどれでもない。
- 型が違う。範囲外である。
- その `type` に無いプロパティを持つ。
- `stepDistance` が 0 より大きいのに、`forwardSeconds` または `backSeconds` が 0 以下である。
- 位置を持たないインスタンスへの、コマンド列中の最初の `position` の `seconds` が 0 でない。
- `instanceId` が `instances` に無い。

### 2.1 インスタンス

インスタンスはチップの呼び出し名である。宣言しただけでは画面に出ない。同じキャラクター、同じアイテム、同じエネミーに、別の `id` で複数対応させてよい。`instances` の並びが、チップの重なりである。添字 0 が最前面、末尾が最背面である。再生中にこの並びは変えない。

同じものを手前と奥の両方に置ける。たとえば英雄 A を B より手前にも奥にも出せるようにするときは、`heroId` が同じインスタンスを二つ書き、手前用を B より前、奥用を B より後ろに置く。`id` は別である。見せる方だけに位置と向きを付けると、描く A が入れ替わる。

劇の開始時、インスタンスは位置も向きも持たない。画面の外にいることは、インスタンスを消したことではない。

| プロパティ | 型 | 意味 |
| --- | --- | --- |
| `id` | 空でない文字列 | コマンドが対象にする名前 |
| `kind` | `character`、`item`、`enemy` | 種別 |

`kind` ごとに、参照プロパティは一つだけ持つ。

| `kind` | 参照 | 型 | 意味 |
| --- | --- | --- | --- |
| `character` | `heroId` | 空でない文字列 | 英雄の id。`Hero` の `heroId` と同じである。パーティーにいるかどうかでは選ばない |
| `enemy` | `enemyId` | 空でない文字列 | エネミーカタログの id |
| `item` | `itemId` | 空でない文字列 | アイテムカタログの id |

## 3. コマンド

コマンドは無限継続系か有限系である。

無限継続系は、同じ対象の同じ `type` を次に実行するまで続く。上書き後の状態も、その次の上書きまで続く。背景と、インスタンスごとの `facing` は別の状態である。止めるための別 `type` は無い。止めるときは、止めた状態の同じ `type` で上書きする。

有限系の `seconds` は 0 以上の数で、単位は秒である。`wait` は数で、単位は秒である。`seconds` が 0 より大きいときは、開始した瞬間の表示上の値を始点、コマンドの目標を終点として、その秒数で直線補間する。秒数が終わると補間は終わり、終点だけが残る。`seconds` が 0 のときは、補間を作らず、その場で終点だけを残す。

`wait` は、次のコマンドをいつ始めるかである。補間の長さとは別である。

- `wait` が負のときは、このコマンドの `seconds` が終わるまで次を始めない。負の数の絶対値は使わない。既定値は -1 である。`seconds` が 0 なら、その場で次へ進む。
- `wait` が 0 のときは、開始した直後に次へ進む。
- `wait` が 0 より大きいときは、アニメーションが終わっていても途中でも、その秒数のあとで次へ進む。

有限系の対象は次である。`position` は `instanceId`。`pinchOut` と `pinchIn` は `view` の `clip`。`line` はセリフ。同じ対象の有限系が終わる前に次の有限系を開始したときは、前の補間を捨て、その瞬間の表示上の値を新しい始点にする。

### 3.1 `background`

無限継続系である。対象は背景一つである。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `asset` | 文字列 | `''` | `public/` からの背景画像パス。空なら絵は無い |
| `scrollX` | 数 | 0 | 横の速さ。基準座標の px/秒。正は右、負は左、0 は停止 |
| `offsetX` | 数 | 0 | 開始時の画像左端の変位。負の値で画像の右側を表示する |

実行した時刻を始点として、画像の位置を 1.3 の式で計算する。次の `background` はアセット、`scrollX`、`offsetX` を置き換え、経過秒を 0 に戻す。

### 3.2 `facing`

無限継続系である。対象は `instanceId` のインスタンスである。足の座標は変えない。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `instanceId` | 文字列 | `''` | 対象の `id` |
| `direction` | `left` または `right` | `right` | 前方向。絵もこの向きを向く |
| `stepDistance` | 0 以上の数 | 0 | 前方向への振れ幅。基準座標の px。0 は足踏みを止める |
| `forwardSeconds` | 0 以上の数 | 0 | 前へ出る時間。秒 |
| `backSeconds` | 0 以上の数 | 0 | 後ろへ戻る時間。秒 |
| `phase` | 0 以上 1 未満の数 | 0 | 実行した瞬間の、そのインスタンスの周期上の位置 |
| `chipRadius` | 0 より大きい数 | 96 | 円の半径。基準座標の px。96 は英雄チップの半径である |
| `fillColor` | 空でない文字列 | `#ffffff` | 円の地の色。CSS 色 |

周期は `period = forwardSeconds + backSeconds` 秒で、インスタンスごとに持つ。`stepDistance` が 0 より大きいとき、実行してからの経過秒を `elapsed` として、周期上の位置 `u` は `(phase + elapsed / period) mod 1` である。前へ出る区間の長さは `forwardSeconds / period` である。

- `u` がその区間より小さいとき、オフセットは `stepDistance * u / (forwardSeconds / period)` である。
- それ以外のとき、`v = (u - forwardSeconds / period) / (backSeconds / period)` として、オフセットは `stepDistance * (1 - v)` である。

`phase` の 0 は、その `facing` を実行した瞬間の周期の先頭である。0.25 は、その周期の 4 分の 1 である。別インスタンスとのずれは、それぞれの実行時刻の差でも生じる。これは許容する。足踏み中に別の足踏みへ置き換えたときは、その実行時刻と新しい `phase` から `u` を計算し直す。

このオフセットには、0 から 1 の係数を掛ける。足踏みしていない状態から `stepDistance` が 0 より大きい `facing` を実行したときは、0.1 秒で係数を 0 から 1 にする。足踏みしている状態で `stepDistance` が 0 の `facing` を実行したときは、それまでの周期を 0.1 秒続け、係数をその時点の値から 0 にする。0.1 秒が終わったあとのオフセットは 0 である。足踏み中の置き換えでは、係数を 0 に戻さない。

### 3.3 `pinchOut`

有限系である。対象は `view` の `clip` である。終点の `clip` は `{ x: 0, y: 0, width: 560, height: 400 }` である。始点は、開始した瞬間の `clip` である。`x`、`y`、`width`、`height` をそれぞれ直線補間する。再生開始時の `clip` からこの終点へ補間すると、矩形は基準座標の中央を固定したまま全体まで広がる。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `seconds` | 0 以上の数 | 0 | 終点までの時間。秒 |
| `wait` | 数 | -1 | 次のコマンドまでの待ち。秒。負は、このコマンドの `seconds` が終わるまで待つ |

背景はすでに 560×400 で描かれており、開いていく矩形にその背景を見せる。

### 3.4 `pinchIn`

有限系である。対象は `view` の `clip` である。終点の `clip` は `{ x: 280, y: 200, width: 0, height: 0 }` である。始点は、開始した瞬間の `clip` である。`x`、`y`、`width`、`height` をそれぞれ直線補間する。全体の `clip` からこの終点へ補間すると、矩形は中央へ閉じて、見える範囲はなくなる。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `seconds` | 0 以上の数 | 0 | 終点までの時間。秒 |
| `wait` | 数 | -1 | 次のコマンドまでの待ち。秒。負は、このコマンドの `seconds` が終わるまで待つ |

### 3.5 `position`

有限系である。対象はインスタンス一つである。終点は (`x`, `y`) で、足の位置、基準座標の px である。`seconds` が 0 のときは、その座標を位置として持つ。0 より大きいときは、開始した瞬間の足の位置を始点として直線補間する。位置を持たないインスタンスへの最初の `position` は、`seconds` が 0 である。0 でないシナリオは不正である。

二人を同時に動かすときは、それぞれへ `wait` が 0 の `position` を続ける。先の `wait` 0 は次の開始を止めない。同時に動かすための別 `type` は無い。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `instanceId` | 文字列 | `''` | 対象の `id` |
| `x` | 数 | 0 | 足の x |
| `y` | 数 | 0 | 足の y |
| `seconds` | 0 以上の数 | 0 | 終点までの時間。秒。0 は即時 |
| `wait` | 数 | -1 | 次のコマンドまでの待ち。秒。負は、このコマンドの `seconds` が終わるまで待つ |

### 3.6 `line`

有限系である。対象はセリフ一つである。吹き出しは `instanceId` のチップの `direction` 側に出す。本文は `text` だけである。`seconds` が終わると、その吹き出しだけを消す。`wait` が 0 のときは、この吹き出しを出したまま次のコマンドを始める。

| プロパティ | 型 | 既定値 | 意味 |
| --- | --- | --- | --- |
| `instanceId` | 文字列 | `''` | この文のインスタンス |
| `text` | 文字列 | `''` | 表示する文 |
| `width` | 0 以上の数 | 512 | 本体の幅。基準座標の px |
| `direction` | `down`、`up`、`left`、`right` のいずれか | `down` | チップから見た吹き出しの側 |
| `seconds` | 0 以上の数 | 0 | 表示している時間。秒 |
| `wait` | 数 | -1 | 次のコマンドまでの待ち。秒。負は、このコマンドの `seconds` が終わるまで待つ |
| `borderColor` | 空でない文字列 | `#9b7142` | 吹き出しの枠の色。CSS 色。寸劇の枠と同じ金色 |
| `backgroundColor` | 空でない文字列 | `#1c140c` | 吹き出しの地の色。CSS 色。既定は文字の縁と同じ |
| `backgroundOpacity` | 0 以上 1 以下の数 | 0.6 | 吹き出しの地の濃さ。0 は透明、1 は不透明 |
| `color` | 空でない文字列 | `#f4ead2` | 文字の色。CSS 色 |
| `outlineColor` | 空でない文字列 | `#1c140c` | 文字の縁の色。CSS 色 |
| `outlineWidth` | 0 以上の数 | 2 | 文字の縁の太さ。基準座標の px。0 は縁なし |

記述例である。`borderColor`、`backgroundColor`、`backgroundOpacity`、`color`、`outlineColor`、`outlineWidth`、`direction` は省略しているので既定値になる。数値は例であり、特定の劇の仕様ではない。

```js
{ type: 'line', instanceId: 'speaker', text: '……', width: 280, seconds: 2, wait: -1 }
```

## 4. 再生

再生開始時の状態は次である。

- 次に開始するコマンドの添字は 0 である。
- 経過秒は 0 である。
- 背景は無い。
- `view` は 1 の再生開始時の状態である。
- セリフは無い。
- どのインスタンスも、位置も向きも持たない。
- ゲーム時計は、理由 `vignette` で停止する。再生が終わったら、その理由だけを解除する。スキップで終えたときも同じである。

時刻は再生開始からの秒で進む。背景のスクロールと `facing` のオフセットは、この時刻で毎フレーム計算する。次のコマンドを止めているあいだも、この計算と、すでに開始した補間は進む。

コマンドの開始は次の規則で行う。

1. 添字が `commands` の長さに達しているとき、次のコマンドを止めていなければ再生を終える。まだ終わっていない補間が残っていても待たない。
2. 添字のコマンドを開始し、添字を 1 進める。
3. 無限継続系なら、状態を上書きして 1 へ戻る。
4. `seconds` が 0 なら終点を残す。0 より大きいなら補間を開始する。
5. `wait` が 0 のとき、または `wait` が負で `seconds` が 0 のときは、1 へ戻る。
6. `wait` が 0 より大きいなら、その秒数が終わるまで 1 へ戻らない。
7. `wait` が負で `seconds` が 0 より大きいなら、その `seconds` が終わるまで 1 へ戻らない。

有限系の補間は、開始時刻を `t0`、現在時刻を `t`、`seconds` を `d` として、割合 `clamp((t - t0) / d, 0, 1)` で始点と終点を結ぶ。割合が 1 になったあと、状態は終点のままである。

## 5. 描画

絵は基準座標の 560×400 で描く。順序は、背景、チップ、セリフである。チップは `instances` の末尾から添字 0 へ向かって描き、先に描いたものが奥になる。添字 0 が最前面である。位置を持っていても `facing` を一度も受けていないインスタンスは描かない。`facing` を持っていても位置を持たないインスタンスは描かない。画面へ出すときは、`view` の `clip` で切り、`offsetX` と `offsetY` を加えた収め位置へ `scale` で置き、`opacity` を掛ける。枠は、切った矩形の外辺に付ける。
