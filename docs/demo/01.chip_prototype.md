# デモシナリオ仕様

本書は検証専用のデモ仕様であり、ゲーム本体の仕様ではない。

## デモ専用の入力と初期状態

- 起動時にランダムな4 Heroを準備エリアへ落下配置する。
- 行き先Item（買い物袋・英雄免許・更新届）を各1つ、倉庫内のランダム位置へ落下配置する。
- `item を追加` ボタンはランダムな装備Itemだけを倉庫へ追加する。行き先Itemは生成しない。
- ランダム追加Itemは頭・胴・手・脚を対象とし、0〜3個のタグを持つ。

## 確認用表示

- 戦闘エリアの敵6枠・味方4枠、ショップ・ギルド・訓練のHeroスロット枠は、配置確認用のデモ専用ガイドである。
- 最小戦闘は攻撃ごとにブラウザコンソールへ `[Battle]` ログを出す。ログには攻撃者、対象、攻撃種別、ダメージ量、残りHPまたはスタミナを含める。ユーザー向けゲームログには記録しない。
- 敵全滅時に戦闘エリアへ表示する経過tickは、デモ専用の計測表示である。

## ゲーム実装との境界

- `src/chips/` は実ゲームで使う共通Chipライブラリであり、デモ操作を含まない。
- `src/game/` はHero、Item、Enemy、施設、戦闘、選択などのゲーム実装である。
- `src/demo/DemoScenario.js` はランダム生成と確認用ガイドだけを担当する。
- ランダム生成は確認用の入力方法であり、ゲーム本番の生成契機を定義しない。
