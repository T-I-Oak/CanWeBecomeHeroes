## 使用したプロンプト

Use case: logo-brand. Asset type: raster transparent certification seal for a fantasy Hero Guild examination pass certificate in a Japanese RPG. Create one beautiful official round vermilion-red ink seal, authentic stamped ink / engraved heraldic linework, confidently designed and far more sophisticated than a simple circle/star. Center emblem: elegant upright sword incorporated into a shield, small radiant star above, restrained laurel branches and ornate concentric border. Strong bold central silhouette, refined medieval guild heraldry, coherent balanced composition, legible at about 90px displayed size on warm cream parchment. Single muted deep vermilion ink, subtle natural ink texture; not gold, not metallic wax, no 3D perspective. Front-facing straight-on symmetrical centered seal with comfortable transparent margins. No paper/background, no external shadow, genuinely transparent background. No words, letters, numbers or watermark. Focus on certification, accomplishment and dignified heroic authority, not ominous imagery. Only the isolated seal asset.
