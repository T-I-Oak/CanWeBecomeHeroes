# 画面の手動確認

通常のVite開発サーバーを起動し、以下のURLを開く。これらは開発用入口であり、通常の本番ビルドには含まれない。自動テストの配置と要求との対応は[テスト構成](../README.md)を参照する。

## 情報ウィンドウの多言語表示

`/CanWeBecomeHeroes/tests/manual/localization.html`

本番のGameTextRepositoryと情報ウィンドウRendererを使う。言語選択は共通設定へ保存されるため、確認後は元の言語へ戻す。

Detailにはエリア、施設、ステータス、タグ、用語、Item、Hero、固有スキルを列挙する。固有スキルはEx1・Ex2を含む共通の静的情報を開く。件数は現行リソースから生成する。敵の詳細は実ゲームまたはレコード画面から確認する。

Itemは代表の画像とタグを用いる。個別のItem画像ではなく、多言語の文言・参照・配置を確認するための入口である。

1280×720、800×600、390×844を目安に、日本語と英語で以下を確認する。

- ウィンドウが画面内に配置され、本文が横にはみ出さない。
- 長い本文を内部の縦スクロールで最後まで読める。
- Hero、タグスキル、施設など長さの異なる説明で、文字と操作が収まる。

`node scripts/review-localization.mjs`で日英文言を出力できる。言語リソースの整合性と設定・状態維持の回帰検証は`npm.cmd test`で行う。

## アチーブメント取得トースト

`/CanWeBecomeHeroes/tests/manual/achievement-toast.html`

初取得・細分段階更新・8件同時追加・モーダル中の待機・破棄と再作成を操作する。演出の静止と100ms進行で、各行の判定変化と寿命を確認する。言語選択はこの確認ページ内の表示言語だけを変える。

## 実力判定試験

`/CanWeBecomeHeroes/tests/manual/challenge-mode.html`

本番の描画・チュートリアル・終了通知・レコード画面を、保存しない表示用サンプルへ接続する。ページのバージョンが実ゲームのタイトル・倉庫のバージョンと一致することを確認する。

- 課題を1・7・8・14・15・21・22へ切り替え、背景帯が7課題ごとに紫系と赤系で塗り替わることを確認する。
- 専用チュートリアルを開き、承認済み本文3ページとボタンの収まりを確認する。
- 終了通知は第8課題到達・7課題クリアーの4人パーティーを表示する。導入演出、二つ名、判定日、署名・印・紙吹雪がないこと、表裏操作を確認する。
- クリアー済みのチェックを切り替えてレコードを開き、実力判定試験タブの非表示・表示を確認する。クリアー課題数は7、経過時間は8日0時間となる。
- 日本語・英語とPC・スマートフォン縦横で確認する。言語選択は共通設定へ保存されるため確認後は元に戻す。

## 終了結果の共有

`/CanWeBecomeHeroes/tests/manual/result-sharing.html`

表示用サンプルで、プレイ記録は保存しない。日本語・英語、合格・不合格・実力判定、長い二つ名を選択して「共有画像を表示」でPNGを確認する。「終了画面を開く」から裏返し・結果をシェアする・タイトル復帰を操作できる。画像はタイトル画像→通知→成績表10件→copyrightの順。端末の縦横や表示中の面によって内容が変わらず、紙の質感・文字色・罫線・印影が画面と一致することを確認する。

PCでは画像コピー後の確認画面から「Xを開く」で本文入りの投稿画面を開き、画像を貼り付ける。「閉じる」・EscapeではXを開かない。モバイルでは端末の共有画面へ画像・本文が渡ることを確認する。クリップボードや共有機能の非対応・権限不足では失敗案内が出る。キャンセル後の再操作、生成失敗時の案内と再試行も確認する。ページのバージョンと実ゲームのタイトル・倉庫のバージョンが一致することを確認する。実機での検証済みを意味しない。

言語選択は共通設定へ保存されるため、確認後は元に戻す。
