# 操作・モバイル表示の確認

## 操作一覧

確認前に以下を固定する。縦390×844、横844×390、タブレット768×1024で確認する。実機Safari・Androidブラウザの指操作はオーナー検証候補とする。

| ID | 操作 | 期待結果 |
| --- | --- | --- |
| INPUT-01 | チップをタップ | 対応する情報ウィンドウが開く |
| INPUT-02 | 情報ウィンドウの閉じるボタンをタップ | ウィンドウが閉じる |
| INPUT-03 | 準備エリアでスタミナ3以上のHeroから倉庫Itemへドラッグ | Heroが指定Itemへ出発する |
| INPUT-04 | 倉庫Itemから買い物袋へドラッグ | 格納可能なItemが袋へ入る |
| INPUT-05 | 拡大したマップでチップを画面内の端56pxへドラッグして保持 | 端へ近づくほど速くスクロールし、限界で止まる |
| INPUT-06 | ドラッグ中にポインタを画面外へ出す | 自動スクロールが止まる |
| INPUT-07 | 水滴表示をタップ | 対応するHeroへカメラが移動する |
| INPUT-08 | 準備エリアのHeroの水滴から倉庫Itemへドラッグ | 対応Heroを選択元として出発する |
| INPUT-09 | チップから水滴へドラッグして離す | 対応Heroを選択先にする。既存ルールで無効な組合せは移動しない |
| INPUT-10 | ドラッグ中に2本目の指を置く | 選択を解除してピンチに移る。すべて離すまでタップ・ドロップしない |
| INPUT-11 | 空白をドラッグ | カメラを手動移動する。エッジスクロールはしない |

現行の操作はHero→Itemの出発指定とItem→袋の格納であり、任意チップの移動・入れ替えではない。水滴も同じ組合せ判定を使う。

## 表示一覧

- 初期倍率でマップ全体が収まり、拡大後は各エリアへ移動できる。
- 設定、出撃選択、課題選択、結果のダイアログが収まり、内部スクロールで操作ボタンへ到達できる。
- HUD上に重なる水滴のドラッグがページスクロールやブラウザズームに奪われない。
- 情報ウィンドウの本文を内部スクロールでき、閉じるボタンを操作できる。
- 画面回転後もカメラの倍率が許容範囲内にあり、ページ全体がスクロールしない。

## 確認結果

実施結果は実装報告に記録する。ブラウザのサイズ変更による表示確認、Pointer入力の自動テスト、実機の指操作は区別する。
